# C2C｜拖拽实例化：把词拖进世界并选择形状

> Claude → Codex（Astra）实操文档。日期 2026-11-17。
> 本文只描述设计与实现方案，不代表已实现。开工前请先读 `AGENTS.md`、`Assets/Docs/README.md`、`Assets/Docs/V5.md`（「开阔场景与 Chapter I」「句子系统结构」）。

> 标记约定：**【已定】** 用户已确认；**【建议】** Claude 的方案，可改；**【待确认】** 需要用户回答，未答前按「默认」实施，并保持可配置、易回退。

## 1. 范围

在现有「开阔地把 light 拖出面板 → 生成一盏方块灯」的基础上，加入**形状选择**：松手后弹出一个小选择框，玩家选形状，再在松手处生成对应形状的实例。

本轮只在开阔地开放，代码里留按区域开关的设置，以后可在 Chapter I 打开试解谜；本轮不参与任何解谜。

因为自由创造目前不能保证可逆，同时加入**右键恢复**：玩家可以撤销自己生成的实例（§4.6）。

## 2. 已定设计【已定】

1. 玩家把词拖出面板并松手时，弹出**黑底 UI**：一排**白边方格**，每格放一个几何形状，暂定**圆、方、菱形**。
2. 选中后在**松手处**生成实例，例如 light × 方 = 方形灯。
3. 本轮**只在开阔地**开放。
4. 代码里留**按区域开关**的设置（白名单／标记），以后可以在 Chapter I 打开试。
5. 本轮**不参与解谜**。
6. 本轮只让 **light** 可以这样使用。
7. **右键恢复**：自由创造目前不能保证可逆，所以加入右键恢复。**单击右键**对着自己生成的实例，只删除这一个；**对着空处长按右键约 1 秒**，准星上出现一圈进度，满了以后所有玩家生成的实例一起反向消散。不做「清空」图标，不往形状选择栏里加格子。

## 3. 现有实现（起点）

| 环节 | 位置 | 现状 |
|---|---|---|
| 拖出面板松手 | `Scripts/V5/Cognition/CognitionBoard.cs` → `EndDrag(screen)` | 单词松手点不在 `panel.ContentRoot` 内时调用 `entry.outdoor.TryWorldDrop(this, token.Meaning, screen)`，然后 `CancelDrag()` 并 `State.ReturnToLibrary(...)`，词立即回到词库。 |
| 是否允许 | `OutdoorPassage.TryWorldDrop` | 只接受 `word=="light"`、在室外、未在过渡、面板开着且未锁输入、玩家已知该词、松手点在屏幕内且不在面板内。 |
| 生成位置 | `OutdoorWorld.TrySpawnInView(screen)` | 从松手点发射射线；命中则取命中点沿法线外推，否则取 `airSpawnDistance`(8 米)；不低于地面；在 `spawnSearchRadius` 内尝试 `spawnAttempts` 次，检查视野内、无遮挡、`CheckSphere` 无重叠、与其它灯间距 ≥ `minimumLampSpacing`。 |
| 生成灯 | `Outdoor/OpeningLightField.Spawn(position)` | `CreatePrimitive(Cube)`，对角线朝下的立方体，`OpeningLight` 外观 + 点光 + `LightMotion`，淡入显现；忽略与玩家的碰撞；加入 `lamps` 参与室外 on／off light、移动句、light light。 |
| 室外灯参与句子 | `OutdoorWorld`（`ISwitchableLight`、`ISentenceMovable`、`IBrightenableLight`）、`LightSentenceEffects` | 新形状的灯必须同样被这些句子识别。 |
| 区域范例 | `ClosureRegion.cs` | 现有「放一个触发范围组件、独立配置」的做法，可参考。 |
| 现有形状资源 | 教学房小球（球）、飘灯房方块灯（立方体）、Blender 八面体星芒（V5.md 提到保留为备选资源） | 八面体可复用该资源，或用代码生成 6 顶点网格。 |

## 4. 方案

### 4.1 交互流程【建议】

1. 玩家在 Tab 面板中拖起 light，在面板外松手。
2. 若当前区域允许实例化（§4.3）且该词可实例化（§4.4），**不立即生成**，而是在松手点弹出形状选择框；被拖的词按现有逻辑回到词库（拖拽图形照常立即移除）。
3. 选择框打开期间：面板保持打开，鼠标保持解锁；世界照常运行（不暂停）。
4. 玩家点击某个方格 → 选择框收起 → 在**松手时记录的屏幕点和射线**处生成该形状的灯（沿用 `TrySpawnInView` 的位置搜索）。
5. 取消：按 Esc、右键、或点击选择框外部 → 收起，不生成。Esc 只关选择框，不同时关闭 Tab 面板。
6. 生成失败（找不到合法位置）时：选择框收起，在松手点给一个弱涟漪／淡出的小提示，不生成（【待确认】Q4）。
7. 区域不允许时：保持现在的行为（词回到词库，什么也不发生）。

> 说明：「松手处」在世界中按松手那一刻的视线计算。如果玩家在选择框打开期间转动了视角（面板打开时视角通常不可转，但需确认），仍使用松手时记录的射线。

### 4.2 选择框 UI【已定外观 + 建议细节】

- **【已定】** 黑底，一排白边方格，每格一个几何形状：圆、方、菱形。
- **【建议】**
  - 新 UI 组件 `Scripts/V5/UI/ShapePicker.cs`，放在 `V5Interface` 的 Canvas 下，处于面板之上。
  - 尺寸：方格约 56×56 像素，间距 8 像素，白色 1.5 像素描边，内部形状为白色线框（与符号的细线风格一致），黑底带 8–10 像素内边距；整体以松手点为中心，略偏上方，避开指针；靠近屏幕边缘时向内夹取，完全留在屏幕内。
  - 出现：0.12 秒淡入 + 轻微放大（0.92 → 1），与历史栏的收起时长同量级。
  - 悬停：方格描边与形状变亮（对齐现有按钮「未悬停较淡、悬停更白更亮」的规则），可附带反色白底黑形。
  - 键盘：1／2／3 选择，Esc 取消（可选，成本低）。
  - 形状图标用 UI 原生 Image + 小 PNG（`Sprites/V5/Shapes/`）或 UI 线条绘制，不引入新插件。

### 4.3 区域开关【已定方向 + 建议实现】

- **【建议】** 新组件 `Scripts/V5/WorldDropRegion.cs`：
  - 字段：`bool allowInstantiation`、`string[] words`（允许的词，默认 `{"light"}`）、`InstanceShape[] shapes`（允许的形状，默认全部）、`int priority`。
  - 判定方式二选一（推荐 A）：
    - A. **按空间标记**：组件挂在空间根对象上（`OutdoorWorld` 根、`ChapterRoom` 根、Garden 根），由当前所在空间决定。和现有 `OutdoorPassage.IsOutside` / `InChapter` / `CurrentRoom` 的空间解析一致，最简单。
    - B. **按触发范围**：组件带 Trigger Collider，玩家位于范围内时生效，多个重叠时取 priority 最高的；以后可以在 Chapter I 的某个房间局部开放。
  - 本轮配置：`OutdoorWorld` 预制体上一个 `allowInstantiation=true`；`ChapterI.unity` / `ChapterI_Garden.unity` 上各放一个 `allowInstantiation=false`（打开即可试用）；P5 室内不放（视为不允许）。
- 「当前区域」的判断与批次 1c 新增的空间解析共用同一套空间划分，不另写一套。
- 把 `OutdoorPassage.TryWorldDrop` 中写死的 `word!="light"` 和 `!IsOutside` 改为查询当前区域的 `WorldDropRegion`。
- 要在 Chapter I 生效，`ChapterRoom` 还需要一个类似 `TrySpawnInView` 的生成入口和自己的灯列表，且这些灯要接入 `ChapterRoom` 已实现的 `ISwitchableLight` / `ISentenceMovable` / `IBrightenableLight`。**本轮只预留接口，不实现 Chapter I 的生成**（【待确认】Q5）。

### 4.4 生成的实例【建议】

| 方格 | 生成的立体 | 碰撞 | 备注 |
|---|---|---|---|
| 方 | 立方体灯（**等同现有**：`OpeningLightField.Spawn` 的对角朝下立方体） | BoxCollider | 保持现有外观，作为回归基准。 |
| 圆 | 球形灯 | SphereCollider | 外观对齐教学房小球：白色灯体、均匀自发光、Bloom。 |
| 菱形 | 正八面体灯（菱形的立体） | 凸 MeshCollider | 可复用 Blender 八面体资源或代码生成网格；轴竖直，上下尖。与走廊菱形星呼应。 |

- `OpeningLightField.Spawn(position, scale)` 增加 `InstanceShape shape` 参数；按形状选网格和碰撞体，其它部分（`OpeningLight`、点光、`LightMotion`、淡入、忽略玩家碰撞、加入 `lamps`）全部共用。
- 尺寸：三种形状使用相同的「视觉体积」区间（现有 `scaleRange` 0.12–0.35），球和八面体按包围半径换算，避免某种形状明显大一圈。
- `TrySpawnInView` 的重叠检查半径按形状的包围半径计算（目前写死 `scaleRange.y*.8661f`，即立方体半对角线）。
- 生成的灯在句子里都是 light：on／off light、light move、light light、no move 对三种形状表现一致；方形灯行为必须与现在完全相同。
- 形状仅影响外观与碰撞，**不**改变句子语义，也不参与解谜（【已定】本轮不参与解谜）。
- 数量上限：建议 `maxInstances`（默认 24）。超过时拒绝生成并给弱提示（【待确认】Q3）。

### 4.5 句子反馈【建议】

- 成功生成：沿用现有世界投放的反馈（如有）；没有的话在生成点播放灯的淡入即可，不加额外字幕。
- 现有「拖出面板松手时立即移除拖拽图形、不在面板内播放消融」的规则保持不变。

### 4.6 右键恢复【操作方式已定，细节为建议】

已定：单击右键删一个；对着空处长按右键约 1 秒全部恢复，准星出现进度圈；不做清空图标（见 §2 第 7 条）。

**【建议】**
- **单个恢复**：游戏中（面板关闭、准星状态）对着**玩家自己生成的实例**按右键，该实例反向消散：先停止运动、熄灭点光，再沿生成时的显现效果倒放（缩小 + 淡出，约 0.6 秒），像「回归理念」；结束后从 `lamps` 移除并销毁。
- **只作用于玩家生成的实例**：生成时给实例加标记（例如组件 `PlayerInstance`，记录形状、生成时间、所属区域）。场景原有的灯、从 Intro 地洞转移来的灯、教学球等一律不响应右键。
- **瞄准反馈**：准星对着可恢复的实例时，显示一个与收集眼睛不同的小提示（例如细线圆环内一个回退箭头，或沿用眼睛但右下角加小标记），让玩家知道右键可用。对着不可恢复的物体不显示。
- **瞄准判定**：沿用现有收集瞄准的射线与距离（`Collection Distance` 同量级），按实例的实际碰撞体判定。
- **全部恢复**：准星不对着任何玩家实例时按住右键，准星外围出现进度圈，约 1 秒满；满的当帧，当前区域内所有玩家实例按距离由近到远错开约 0.05 秒依次反向消散，形成一波回收。进度圈直接复用长按观察的 `ObservationRing`（同样的开口、粗细与背景对比材质），时长单独配置（默认 1.0 秒，观察是 0.8 秒）。中途松开、打开面板或开始对准某个实例都重置；每次按住只触发一次。没有任何玩家实例时不显示进度圈。
- **单击与长按的区分**：对着实例时右键按下即开始判定，松开时间短于短按阈值（沿用 `Click Duration` 0.25 秒）才删除该实例；对着实例按住不放不触发全部恢复，避免误清空。
- **与句子的关系**：消散过程中实例不再参与 on／off light、移动句等；一次性句子的作用范围按执行时计算，已被恢复的实例不影响句子完成判定（避免 off light 等待一个已销毁的灯）。
- **按键冲突**：选择框打开时右键用于取消选择框（§4.1）；选择框关闭时右键才用于恢复。确认现有输入中右键没有其它绑定。
- 区域开关同样适用：`WorldDropRegion` 允许实例化的区域才显示恢复入口；区域外已生成的实例（理论上没有）不受影响。

## 6. 实现步骤

1. **形状枚举与生成**：`InstanceShape { Cube, Sphere, Octahedron }`；`OpeningLightField.Spawn` 支持形状；八面体网格与凸碰撞；`TrySpawnInView` 按形状半径检查。先用临时调试入口（Inspector 按钮或编辑器检查）验证三种形状都能生成并参与室外灯句。
2. **区域开关**：`WorldDropRegion` 组件与当前区域解析；`TryWorldDrop` 改为查询区域；`OutdoorWorld` 允许，Chapter I／Garden 放置但关闭。
3. **选择框 UI**：`ShapePicker`（黑底、白边方格、三个形状、悬停、淡入、屏幕边缘夹取、Esc／右键／点外部取消、可选 1／2／3）。
4. **接线**：`CognitionBoard.EndDrag` → `TryWorldDrop` 在允许时打开 `ShapePicker`，保存松手屏幕点与射线；选择后调用生成；取消时什么也不做。词回库逻辑保持现状。
5. **右键恢复**：`PlayerInstance` 标记；右键瞄准判定与提示图标；单击删除与反向消散；对着空处长按右键 1 秒的进度圈（复用 `ObservationRing`）与全部恢复；与一次性句子完成判定的兼容。
6. **检查脚本**：新增 `Editor/WorldDropChecks.cs`（或扩展 `OutdoorChecks`），在全新 P5 Play 中覆盖 §7 可自动化的项目。
7. **文档**：完成后在 `Assets/Docs/V5.md`「开阔场景与 Chapter I」中补一段描述当前行为与区域开关，本 C2C 文档不作为长期设计来源。
