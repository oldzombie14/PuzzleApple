# V5 当前设计与开发

入口：`Assets/Scenes/V5/P5.unity`，可直接 Play。设计与提需使用 [V5 开发工作台](Workbench/README.md)。

## 已确认要求

**全局避免严重影响视觉的大面积过曝，保留原有柔光氛围。** 允许局部强光与光晕影响物体轮廓，不要求所有边缘始终锐利；以大幅收敛前的发光氛围为参考，保留灯体、星芒和增亮句的明显表现，同时限制如通道截图那样大片泛白的极端情况。V5 使用 Neutral 高光响应与有上限的 Bloom 输入，各区域保留自己的柔光强度；light world 的完整增亮为 1.6 档曝光。祭坛白闪过场保留。`ExposureChecks` 输出普通与叠加增亮的实际渲染，参数检查与截图复核共同验收。

**句子的作用范围是当前薄膜区域与已解锁进度的交集。** Intro、开阔地、Chapter I 分别算一章，跨章仍清空组句区。Intro 开局仅包含房间 1，通道首次完全显现后才并入第一段通道；白门首次可通行后并入教学房和外侧轨道。之后逐门并入车库、普通通道、飘灯房和阶梯，感应开门与手动白门遵循同一套首次可通行判定。首次解锁永久保留，不要求进入过后面的空间。带门的进度边界首次解锁后，两侧只在开度大于零时连通，完全关严才隔断作用；门本身可从任一相邻区域操作。无门的进度边界首次解锁后持续连通。花房与维特鲁威人房间由薄膜门隔离，进出时持续句随当前区域切换。一次性开关与定向命令只作用于说出时已纳入且此刻仍连通的区域。离开作用范围的对象保留方向、相位和进度。转头、距离和普通走动不改变范围。一次性定向句覆盖范围内全部符合条件的对象，各空间使用自己的有效锚点；语句镜头只考虑玩家当前空间的目标。light world 与 no move 保持全局作用。

启动即进入闭合的黑方盒，自动打开左侧 Tab，初始符号只有 on／off／world。V5 普通表面（大小盒、通道地面与门、灯群房间墙地顶）统一使用 World Surface Shader，采用纯白哑光与细黑边。通道口流线、灯体发光及 UI 继续使用原专用 Shader；白门保留铰链开合，室内表面保留碰撞涟漪。内外空间墙面统一纯白、统一高粗糙度哑光材质，不混用光滑高光质感；暗度通过照明控制，不把墙材质染灰。空间保持黑白灰；白色表面关闭环境反射与镜面高光，避免关灯后残留蓝色环境反射；灯群自发光使用中性白。小盒墙角与墙顶贴合，不再保留实际缝隙，保留原来的 Shader 边缘亮线；顶部、底面与周围墙面保持相同色相和暗底；外盒沿墙角、顶边和地面边沿显示细黑边；降低均匀补光并拉开地灯与墙面的明暗，保留纯白哑光材质。

拼句的拖拽、涟漪／星芒及音效沿用 V4 的表现，玩法按 V5 独立实现。on game（on + world 符号）使小空间按 V4 的铰链折纸方式展开，露出更大的方形空间。on game／off game 生效时，镜头先保持原地和水平方向，缓缓拉平俯仰，再开始开盒、关盒或显示退出确认。展开时顶板先绕墙顶铰链掀起，随后四墙绕底板边缘向外翻。所有面铺平后整组一起淡去并沉入地面；合拢沿同一轨迹倒放，整组先浮出，四墙立起，最后盖上顶板。展开结束时不自动打开面板。off game（off + world 符号）生效并触发退出确认时先播放带星涟漪，盒子已合上或当前区域直接弹确认时也一样。off game 的电影黑边保持到退出确认 UI，取消确认或中断退出时收起。关盒时冻结玩家位置但保留转向和视角，从玩家脚下反向折合小空间，关回后稍作停顿，再淡入 on／off 确认 UI；on 关闭游戏，off 或 Esc 取消确认并返回游戏；Esc 与 off 使用相同的就绪条件。Tab 右上角及退出确认的 on／off／world 按钮统一为未悬停较淡、悬停更白更亮。目前不做存档，Intro 室内没有背景音乐。

## 语句反馈

`on move` 和 `off move` 都是成立的句子。当前场合没有产生变化时，组句只给不带星的弱涟漪，句子显示为低档。

星表示整条语句的有效连通范围内有潜在响应目标，目标被占用也带星。字符与涟漪的明暗取决于实际响应的位置。

| 说出时的情况 | 星 | 字符与涟漪 | 通用镜头 |
| --- | --- | --- | --- |
| 当前空间有目标响应 | 有 | 字符纯白，涟漪最明显 | 播放当前空间演出 |
| 仅其他连通空间有目标响应 | 有 | 中档 | 保持当前视角和面板 |
| 有潜在目标，全部被占用或受阻 | 有 | 低档 | 保持当前视角和面板 |
| 连通范围内没有潜在响应目标 | 无 | 低档 | 保持当前视角和面板 |
| 语法无效 | 无 | 点击后划线 | 保持当前视角和面板 |

一次性句子只在触发时反馈一轮涟漪。触发镜头或盒子折叠动画时，在画面中央以较小尺寸呈现无描边的原句符号，按句长适配宽度；镜头对准并开始执行效果或盒子开始折叠／展开时，符号开始淡出，演出退出时完全消失；中断演出时收起字幕。

持续句在连通范围内有实际响应时循环泛星。进出空间、门隔断连通或目标状态改变时，更新字符与涟漪。由有响应变成无响应时给一轮低档涟漪，随后停止循环。循环星芒的分布向句子外围扩展，保持原有粒子大小与数量，循环中的双圈涟漪沿用首次生效的展开形态和时长，每轮约 1.8 秒，约 1.49 秒时下一轮开始淡入，与尚可见的上一轮尾波交叠，可在 Sentence feedback 的 Repeat Sparkle Padding 调整水平／垂直外扩范围。玩家关闭 Tab 后世界效果继续执行，重开时按当下状态显示；生效时播放一次提示音，循环和重开面板只重复画面。任何一次性动作完成时，面板关闭即可后台归库，重开时直接显示当前组句。

## 开阔场景与 Chapter I

开阔场景保留两条路线。白色回程门保持初始摆放朝向，不随玩家位置旋转；门内完成状态的符号使用生成灯的亮面、自发光和局部点光。穿过原门时画面短暂淡暗，平视回到充能门的房间一侧，室外音乐淡出。回访沿楼梯走到顶端可再次进入开阔地。穿过独立的金色画框时，画面用 0.75 秒淡黑，场景就绪后用 0.9 秒显现，室外音乐用 2 秒淡出，保留相对入口的水平视角与俯仰，先到 `ChapterI_Lesson` 的教学方盒，再经星空平台进入正式展廊 `ChapterI`。展廊出生点身后的镜子通回开阔地。本次运行往返保留词库、盒子展开进度和灯的位置及明暗。

## 句号生效设计

已确认：V5 正式采用句号设计，替代旧版「拼完即生效」设计。旧机制目前不维护，现有兼容代码与 `Require Period` 开关暂时保留，P5 保持开启；后续开发、修复与验收以句号设计为准，不再要求关闭开关后的行为兼容或双模式回归。

一次性语句共用同一判定顺序。点击句号时，先检查是否已有一次性动作在执行，再检查语法、与生效句的冲突和当前范围内能否实际开始动作。一次性句没有开始执行时仍为草稿，本轮反馈结束后句号重新提示，动作需再次点击。持续句一经说出就保留，目标出现或解除占用后自动响应，拆词或移除句号取消。所有可判定的有效草稿可以同时泛涟漪。

只要一个对象实际开始一次性动作，就锁定新句判定。期间可以收词、拖符号、编辑和拆除其他句子；其他句号点击不记历史、不排队。此时获得的例句保留为草稿。全暗时的 `light move door`、灯均已亮时的 `on light`、无可升目标时的 `floor move light` 都不占用判定。已生效的持续句照常执行。

**一次性语句一经说出并生效，执行中的整句锁定，完成后自动归库。** 这包括灯与门的开关、三词定向移动和世界盒的开合。执行期间不能拆词、换序、拼接、移走句号或整句回收。玩家可以移动整句的位置、编辑其他句子。若要复原，等当前句归库后由玩家自行决定是否说出反向句。例：`door move` 运行时说出 `on door`，门会完成开门，再由仍生效的 `door move` 接着往复；单独使用 `on door` 时，门开完后保持打开。

所有多词组句尾自动出现正圆句号，单独占普通词格；点击才判定效果、冲突、历史和演出。草稿词透明度为 0.16，句号在 0.16–1 间以 2.5 秒周期呼吸，悬停用 0.15 秒渐亮。各条可判定的有效草稿独立显示句号涟漪。已说出的持续句可拆词、拖出句号并在整句外松手来暂停，保持运动方向、相位和进度。从组句区空白处拖框，完整框住单句后才可拖移该句，点击空白取消。移动只改变排版；可编辑的词组在未选中时可拆词。移除句首小点；选中框保留白边与半透明底，选框使用整句涟漪扩散过程中短暂停留时的矩形，保持静止。两者共用内容范围和横纵留边，句号按圆点右缘计入。选中后在框内右键（词、句号或留白）均消融整句，执行中的一次性句保持锁定。对未选中的可编辑词组，右键词只消融该词，右键句号只消融句号并暂停。拖走的圆点淡出后在句尾重新出现；草稿句号不能拖动。不通组合在点击后整句划线并记失败，编辑或暂停清除划线。一次性句完成后连同句号归库；空闲时观察例句自带已说出的句号。没有角落句号、拖拽放置、吸附和尾迹引导；尺寸、命中区、呼吸、悬停、淡隐与涟漪在 Punctuation 中调整。

## 灯化句式

`light world` 提高游戏世界的曝光；`light door` 让门发出柔光；`light floor` 让地板自发光；`light light` 语法成立，增亮有效范围内正在发出的光，包括灯体、星芒和由句子点亮的门与地面。只要范围内有光即可给带星反馈。试验句 no move（否定符号 + move）暂停世界中的运动，包括玩家位移和下落。玩家可转动视角、使用 Tab 编辑句子；灯光开关和 light floor 等静态效果即时响应，已生效的持续运动句保持成立并等待解冻，冻结中无法启动的一次性动作需在解冻后重新点击；拆掉最后一句 no move 后世界从暂停处继续。灯化是持续效果，可与其他灯化、开关和移动句并存。灯化从当前亮度渐入；拆掉最后一条同效果的句子后渐暗恢复。室内和室外共用这套语义。

## 行为观察与持续句子

灯群移动时，无论亮暗，对准同一个可见方块，允许偏出方块边缘约 1.5°，连续按住左键 0.8 秒，进度满的当帧立即弹出 move，复用普通词汇的放大／飞入收词动画，不等松开；暗处观察只收取 move，灯继续示范移动。亮灯时完成观察才收取 light move 例句，即使已经在暗处学过 move。新例句优先放在组句区中部并避让已有词句，自动摆放避开顶部预留区域，再自动打开侧栏，待面板展开后在新句子上播放一次成立反馈。未满时松开、移开、换方块或打开面板会重置观察；每次按住只触发一次，松开后才可再次蓄力。房间 3 的暗方块保留自主漂移与碰撞反弹；不发光时不具备 light 属性，light move 的成立、拆除或取走句号均不能接管或停止它们，先前学会 move 也不改变这一点。亮方块仍保留示范时可自主运动；取得亮灯例句或有效移动句实际作用于亮方块后，由玩家句子接管其发光状态下的运动，拆句暂停、重组沿原方向继续。熄灭后的自由方块恢复自主漂移，再点亮时恢复此前的亮态控制状态；定向运动已有的停靠状态保持原规则。no move 仍全局冻结。floor 符号在句子、词库与历史布局中下对齐，避免横线居中看起来像等号。普通词汇在左键按下时立即收集；只有同时可观察动作的目标才区分短按收词与长按观察，长按取消不转为普通收词，短按的按下和松开必须指向同类词汇目标。短按阈值暂取 0.25 秒，可通过 ChamberLight / Click Duration 调整；外围圆环独立显示动作的未知／已知状态。

ObservationLesson 资产配置习得来源、动词、例句和时长；ObservableBehaviour 维护可观察的移动方块成员；ChamberLight 统一路由左键点击／长按，BehaviourObserver 负责观察与满条立即反馈，ObservationRing 负责原生 UI 圆弧。Aim Tolerance Degrees 控制成员边缘的角度容差。圆环半径、底环／进度粗细、顶部开口、端点圆角对应线宽、静置／观察中底环透明度可调整；圆环直接共用眼睛的实时背景对比材质，不单独指定黑白色。白底呈黑色加载段与浅灰底环，黑底自动反转；完成段加粗，满条立即触发收词反馈。已知动作静置时变淡，长按加载时恢复清晰进度。眼睛由 SpriteContentAlignment 按现有 PNG 的可见图形中心校正网格，原图、UI 框尺寸及收词行为不变；支持 Optical Offset 微调。保持 V5 资源隔离。

已确认：已习得后再次完成观察只显示 move 动词的已习得反馈，不重复生成句子、不打开侧栏、不锁移动；已知动作也在满条时立即弹出已习得反馈，每次按住只触发一次。ObservationChecks 已通过动作目标短按释放收词、动作满条立即收词反馈、长按取消不误收名词、观察中断、已知反馈、习得与侧栏、拆句重组及明暗运动。满蓄力使用独立的一次触发锁存，无动作观察的普通目标按下即收集，不受短按时长限制。实际 UI 已核对白底黑色进度／黑底白色进度，GPU 黑白背景对比与多分辨率对齐检查通过；未验证独立构建，不保存验证截图。

## 灯群地面与下降

### 充能门与白色阶梯

充能门及楼梯的可调参数集中在 `Prefabs/V5/Resources/V5/IntroEnding.prefab`。根对象配置门洞、充能和升降时长；White ascent 子对象配置踏步、渐白高度、地平线与过场音效。

Intro 四扇充能门统一在满能且玩家靠近时上升，离开后关闭。`on door`、`off door` 和 `door move` 仍作用于原白门；充能门的门体可参与 `light door`，升降只由感应驱动。外轨一侧按平台行进速度提前感应。内侧感应距离先按 1.75 米试玩，可在 P5 的 PassageJourney 上调整感应距离与升门时间。

远端充能门和倒 U 形门龛使用墙面底色并叠加自发光；拆掉 light door 后减去门光，显出同光照下的墙面颜色。若在车库尚未接管，首次点击仍可直接打开 Tab 并授予同一个已说出的例句，省去中央 door 收集动画、只播一次成立反馈，门光连续移交句子；再次点击时，门还亮着就并排显示已知的 light 和 door，完全熄灭后只显示 door。重复点击只给词汇提示。拆句后约 0.8 秒淡灭。门上三个浅刻字充满后约 0.8 秒渐亮。

总能量由四部分构成：不可耗尽的底能 0.005、门发光最多 0.4、停靠在充能门的亮灯最多 0.595、未停靠亮灯在门框外 4 米范围内路过最多 0.1。初始门能量 0.145，总量 0.15；入口未解锁时保持初始读数。门发光且停靠亮灯的总供能达标才能到 1，否则最多 0.95。充能速度 0.19／秒、衰减 0.12／秒；light door 不加速，light light 让充能速度 ×1.5，不改容量。路过时最近槽与门框轻微泛光，离开后渐淡。平时充能条和刻字为中性白，只有满能且 light light 生效后才在 1.5 秒内渐变到低饱和橙红（RGB 1／0.90／0.85），拆句或失能后渐白。能量仍从左下、顶边到右下连续填充。先 on light 点灯，再 light move door 停靠，同时保持 light door。房内 cube 按下令时到两门的距离分流，保证正常灯群有足够的供能分给充能门。灯越大供能越多，阈值按初始灯群中十盏平均大小灯的总输出确定，灯减少不降低阈值；暗灯不能充能或聚集。第一段通道的 light move door 仍将星芒聚向白门。满能后靠近升门，离开感应区后降门；失力警告后加速下落，碰到玩家后仰头、淡黑并在身体所在一侧重生，保留句子和机关状态。

## 语法与演出接入

拆词、右键、拖走句号和 `no move` 均暂停运动。运动对象保留当前方向、相位与位置；恢复或重组时使用当前薄膜区域与已解锁进度的交集，不保存旧的作用范围。跨薄膜时，生效中的句子立即切换区域，区域外对象暂停。物理反弹、抛出的灯落地及补入新星仍可改变方向。

所有三词定向移动句采用 A move B。可执行的移动到位或受阻后归库，执行中锁定，依赖灯光的运动在熄灯时暂停。停靠的灯保持位置，直到下一个运动句接管。door move light 和 door move floor 在各空间只给弱涟漪；floor move light 和 floor move door 只在开阔地抬升地面。

SentenceRuntime 区分请求句子与已应用效果：相反灯／门状态互斥，重复同效果可共存；新效果可等待演出开始，拆除持续句立即停止该句效果；一次性命令重试仍需点击句号。跨房间不重放灯句演出。观察授予 light move 直接接管预设运动并打开面板，不因授予过程再收回面板。

SentencePresentation 在反馈后显示电影黑边并应用效果。语句演出默认保持视野。只为当前空间内确实会变化的关键机关轻调视角，保留位置和 roll。on door 可轻调俯仰和水平朝向；第二段通道的 floor move 只向下调俯仰，最多 14°。Room 2 大球首次离开通道口后不再成为镜头目标。通道星辰、Room 3 飘灯、light move door 和 off door 保持视野；Room 3 的充能门由感应驱动，手动门句保持视野。演出正常播完后保留当前朝向，自动锁回鼠标并恢复准星和游戏控制，无需点击，Tab 面板保持关闭，不自动弹出；新效果开始后允许玩家主动按 Tab 中断镜头，保留朝向返回编辑。独立配置 GameData/V5/Resources/V5/SentencePresentation.asset 统一调整进入、停留、退出时长及黑边，不再逐句配置镜头。关键机关通过 SentenceFocusSource 登记可展示空间和当下的聚焦请求，SentenceCameraDirector 在反馈结束后从玩家当前空间与效果范围的交集中选取第一个有效请求；选点时重新检查资格，已停用或销毁的机关不再成为候选。仅其他连通空间响应时保留面板，跳过通用镜头演出。当前空间有响应但没有聚焦请求时使用保持当前视角的默认过场，四条增亮句、Chapter I 的生效句和冻结期间仍可执行的灯光句均覆盖；重复效果与没有变化的句子不额外播放。世界退出保留专门确认流程。FloorDirectedMotion 对尚未完成初始化的引用安全返回，避免先执行物理帧时空引用。

本轮同时移除通道门的固定装饰框，门洞厚度表面与前后边缘应用现有发光 Shader。道路和房间地板仍共边，不叠放。灯群房间墙面和天花板随灯光亮白／变黑，与地面使用一致的明暗；实际墙碰撞产生与地面同参数的双圈涟漪和方形粒子，天花板也接入原生碰撞涟漪。保留独立 Shader 测试会话与 P5 未保存现场。

### 句子系统结构

原则：同一句子对不同物体是同一语义，每类物体自己决定表现。例如 off light 时，走廊星辰在各自剩余的闪烁周期内缩小消失（远处小星更快），方块灯与教学球则按亮度渐暗；SentenceRuntime 和效果处理器不关心具体表现。

- 语法入口：OpeningCatalog 引用 `GameData/V5/Opening/SentenceGrammar.asset`。WordDefinition 的 Classes 标记语法槽位（State、Noun、Verb，可兼任），模板按词类与允许词集合匹配，例外可拒绝组合或改写意图。世界开关、冻结和既有特殊句型通过例外保留；mirror 不进入新模板，原有两条规则显式走兼容路径。
- `SentenceGrammarResolver` 将模板结果转为 `SentenceIntent`（动作、主语、可选目标、句型类别、范围策略）。WordDefinition 的 Property 引用语义性质资产，StateProperty 可单独指定开关对象性质，默认沿用 Property；light 的两项分别为 Light 与 PotentialLight，保证暗灯仍能开灯。意图在解析时保存主语／目标与开关性质引用，不按词的拼写判断效果。CognitionState 在组句时保存解析结果，点击句号才产生效果、冲突、历史与演出；拆词或换序会重新解析并清除旧意图。
- 灯／门开关、运动分发、照亮、冻结和世界开关已按意图选择处理器；开关查询直接使用意图的 StateProperty，物理控制器按主语、目标性质判断运动资格。SentenceRuntime 分别保存已提交意图与作用范围，照亮强度和门的开关优先判断读取已提交意图，演出结束前不提前应用新句子。
- 执行兼容资源仍为 `GameData/V5/Opening/Rules/*.asset`：暂保存原信号、trigger、kind 与冲突通道 channel，解析器用原词序关联绑定，校验 kind 一致。原生句式的兼容信号由 `SentenceLegacySignalBridge` 从意图生成；原规则的 effect 不再决定原生句式的效果，mirror 的 Legacy 路径仍读原规则。模板重叠、重复例外、已支持句式失去模板、缺少性质／控制器适配或模板扩出尚无绑定的组合都会报错。Scope 中的 CommandRegion 由运行时按每次说出的顺序记录空间，演出延迟或冲突解除都沿用这次记录；ExistingController 表示范围仍由原控制器处理；运动控制器和输出归属使用 SentenceMotion 的主语、目标性质。CognitionSignal 仍供目录冲突、旧规则和兼容查询使用。
- [V5 开发工作台](Workbench/README.md) 维护全局规则、符号、语法、具体句子与关卡设计；开发要求按批次提交和验收，阶段进展与完成会话在时间线留档。初稿参考 V5 主档和只读 Unity 快照。原语法窗口已移除，自动校验保留为 SentenceGrammarDiagnostics。语法成立、执行绑定、对象资格和验收分开记录。
- **运动冲突与句号反馈**。P5 按说出次序比较同一运动输出上的目标。目标相同可共用，目标不同由先成立的句子控制该输出。后来一句只要还有可参与的空闲输出就可成立，有实际变化时给带星反馈。所有可参与输出都被占用才算冲突；没有对应目标或运动方式时给无星弱反馈。物体离开范围、重新发光或前句结束时重新分配，自动重判不写历史。只有玩家说出的命令能进入执行；被执行中命令完全挡住的新命令保留草稿，需再次点句号。开关状态句仍按互斥关系判断，执行锁保留到整句完成。
- SentenceRuntime 只做调度：冲突与接管、演出排队、提交已应用效果、命令句完成后归库；它不再按规则 id 写效果。
- 性质与输出端定义位于 `GameData/V5/Capabilities/`，`Resources/V5/SentenceCapabilities` 引用这些资产。`SentenceEntity` 可配置天生性质与查询时现算的性质，并引用状态输出端；当前 PotentialLight 表示可被开关的发光体，Light 按亮度大于零查询，Door 表示门。独立教学球、飘灯房灯体、章节灯及生成灯分别登记，生成、停用、恢复和销毁跟随各自生命周期；星群保持群体实体。原群体／空间控制器暂保留登记，以承载共同渐变与环境光。
- `SentenceStateOutput` 提供当前连续值、是否会变化、是否仍在执行、下令、暂停和完成释放。多个灯体可引用同一控制输出，查询和下令按输出实例去重；增加一个共用亮度的灯体不会重启原渐变，独立输出可以加入尚在执行的命令。充能门的执行中断由自身输出报告，通用门分发不再判断具体门类型。灯的收词与运动资格读取实际发光状态。灯自身的开关和门／地面的句子发光分别控制。
- `SentenceMotionOutput` 保存范围内已应用运动指令，并提供运动资格与等待亮灯查询。`SentenceMotionBindings` 暂为现有场景控制器提供适配，`MotionEffect` 不再包含按空间判断具体物体的查询分支；轨道平台、Intro 灯光和章节灯光控制器读取登记输出；飘灯房的漂移、落地和聚集共享一个位置输出，维特鲁威人房间的生成灯群有独立的位置输出，轨道球沿用房间的运动输出。教学房白门的往复运动读取铰链输出；输出记录提交时的句式与说出次序，避免编辑中的句子沿用旧归属。室外灯群、门和地面使用三个独立位置输出，按控制组件区分同一对象上的登记；提交或释放指令时通知原控制器，原 `OutdoorWorld.ApplyMotion` 集中分发已移除。停用或离开作用范围会清除输出，恢复后按当前持续句重分发，不重置物理位置与相位。门和地面的运动输出在句子点亮它们期间也接受 light move，依各自结构执行；固定地面保持原位。
- 状态和运动输出都通过 `StateSource<T>()` 访问实际控制器。白门的开关与往复共用一个门轴；室外灯群与门框分别恢复。快照记录物理状态，恢复前先检查整组数据及门下占位。当前命令继续驱动，暂停中的输出保持，已归库的开关句释放控制。
- 空间身份由 `GameData/V5/Spaces/*.asset` 的 `SentenceSpace` 资产表示，范围图、实体登记查询、进度锁和薄膜配置使用资产集合；新增资产无需占用枚举位。`Resources/V5/SentenceSpaces` 目录映射让现有位置判定、运动、效果和渲染继续使用 `LightSpace`，这些旧调用者尚不能直接表示未映射的新空间；遇到未映射资产会明确报错，不截断范围。
- 范围由 `SentenceScopePool` 缓存进度与门连通图，再与 `MembraneDoor` 区域取交集。`ProgressLock` 通过单个 Boundary Source 引用实现 `IProgressBoundary` 的组件，订阅进度变化；解锁、连通或配置变化时使图缓存失效，门在同一连通状态下继续运动不重建图，也不在范围查询时轮询门。白门、房间 3 入口门和充能门默认在进度 0.5 时首次解锁，之后不回退，完全关闭才断开连通；首通道显现进度达到 1 后永久连通。运行时绑定用 `BindBoundary`，修改空间用 `SetRegions`／`SetInteriorRegion`，保证订阅与缓存同步。
- 花房与维特鲁威人入口仍用原生触发器结合室内容积判断区域；解锁与跨薄膜会重算已提交效果。`SentenceOwnership` 可表达副本沿用原件归属，跨薄膜镜像特例尚未实现。
- 效果处理器（`Scripts/V5/Effects/`）在当前范围内找到目标，再调用物体接口；定向命令遍历范围内全部符合条件的对象，各空间使用自己的有效锚点：
  - on／off light：`LightStateEffect` → `QueryOutputs(PotentialLight, Emission)` → 状态输出端 → 既有 `ISwitchableLight` 控制器。暗灯也保留 PotentialLight，能参与开灯；现有渐变、星光熄灭节奏和环境光保持。命令保留本次开始时的空间上限，并与当前范围取交集。
  - on／off door：`DoorStateEffect` → `QueryOutputs(Door)` → 状态输出端 → 既有 `ISwitchableDoor` 控制器。白门和房间 3 入口门使用 Hinge，充能门使用 Lift，室外阈值门使用 Emission，Chapter I 教学方盒的充能门使用 Lift。门的执行范围与镜头展示空间分别登记，选取展示目标不缩小执行范围。
  - 运动句（Move 意图；mirror 保留原通道适配）：`MotionEffect` 查询 `SentenceMotionOutput` 的资格与等待状态，提交时按当前作用范围推送指令。`SentenceMotionBindings` 将既有控制器的 `CanMove` 接到输出端；示范接管记录、首次介绍时是否已知 move、运动修订号及重新点亮的续漂判定由各输出端保存。MotionEffect 不再按空间位维护这些状态，房间 3 的亮态接管条件在绑定层提供；词汇知识变化独立于句号请求去重同步，遗忘 move 会清除接管记录，停用期间发生的遗忘在重新登记时也会生效。
  - 照亮句（light world／door／floor／light）：`IlluminationEffects` 渐变四个照明强度，负责后处理与全局发光；灯、门、地面自行读取 LampMultiplier、FloorIllumination 等强度。light light 按整条句子的有效范围查询亮着的实体和地面光。灯体使用既有倍率，门面与地面额外增亮最高 25%。
