# V4 当前设计

当前设计直接维护原段落，不按聊天顺序追加。探索方向和实现取值不视为定稿。Unity 版本：6000.3.9f1。

## 整体方向（探索中）

第一人称探索解谜：在世界中收集符号词，在 Tab 面板组句，以认知改变世界。V4 探索形态、实例与本质／概念的关系，不绑定某一哲学理论。

- 通过多个空间或谜题理解共有概念，避免由单一例子定义概念。
- 拟积累跨关卡复用的概念，用其创造实例；很多具体名词可能只在当地有效，不认定所有名词都清除。
- 动词拟持续跟随玩家，也可能有其它可携带词。分类、词库、世界观和关卡顺序待设计；机制可借鉴物理、化学、数学、音乐等学科。
- 关卡考虑已有能力和概念的依赖，但不等待完整故事定稿。讨论中的例子不是制作清单；旧版等于／本质化的含义不自动继承。

## 当前范围与呈现

先逐步跑通进入正式关卡前的开场小流程，暂不追求高美术质量，也不要求立即展现完整概念积累系统。暂定衔接为起始空间与小谜 → 另一小空间 → 短衔接谜题 → 第一个正式关卡；具体后续内容待用户说明。

- 玩家无实体身体，光点外观暂缓制作；不做草叶，地面只呈草绿色。
- 玩家体验全程无英文，菜单、提示和教学通过符号与动画。文档中的 move 等英文仅为开发标识；缺少正式素材可用 Unity 原生资源占位。
- 黑屏进入界面：中央【正状态 世界】进入，右上角【负状态 世界】退出。主界面符号默认纯白、悬停变灰，无按钮底色；先淡出符号，再淡出黑底并恢复操作。进入世界后右上角退出符号常驻、仍可点击退出；白天默认接近草地色但降低饱和度，镜头朝地面时渐变为近白的微绿，悬停同样为近白微绿；夜晚随夜景主色变化，同样保持低饱和度与明暗层次。主界面与游戏内配色独立。
- 白天低饱和、有光、有高处缓慢移动的云及云影；夜晚无云，冷暗天空与雾、零星高处柔光星星。星星多数暗、少数略明显，以缓慢星芒伸缩闪烁，不铺满天空。
- 云为具有真实离地高度的平面，与天空柔和衔接，无灰边薄膜；云影对应同一云 Alpha，使用原生方向光 Cookie，不在地面另算无关噪声。

## 收词与面板

六词为正状态、负状态、世界、move、灯、门。世界使用 `Apple.png`，灯暂用 `red.png`，不据图片名推断语义。

- 进入场景获得正状态、负状态、世界，Intro 入场自动打开 Tab 面板。Tab 开关左侧面板，保留词库、拖拽组句、拆句、无效句划线、快照与备注；复用布局不表示继承旧玩法。
- 首次行走从生疏到熟练并收 move。首步起至收词动画完成禁止世界物体交互，中途停步不解锁。先点灯则收词结束前暂停位移、保留转向。词在飞入结束时入库，不重复收取。
- 点击发光方块收灯；瞄准点击显现的鱼门收门，沿用眼睛反馈和收词动画。
- 眼睛居中、140×140，普通准星及收词符号保持已有布局和对比效果。无快照时框内显示左下至右上的对角线，有图时隐藏，保留框线与备注。
- 词的提示保留首次获得时的情境：正状态、负状态、世界不配图；灯、门在首次收词时保存对应对象的静态画面；move 使用预录的第一人称踉跄行走循环片段。名词默认静态、动词默认动态，其它词默认静态，无法合适表述的词可无提示。
- 开关 Tab 不等于拆句，不能仅因面板关闭而停止有效移动。

### 句子反馈与 Intro 演出

- 加减字直接更新句子，不再擦除后重写。反馈出现在 Tab 中对应句子周围：成立且实际产生新表现时为方框涟漪加菱形星芒，星芒使用贴图素材与粒子；成立但无新表现时只有较弱方框涟漪；冲突句无涟漪、低透明度；不成立保留划线。
- Intro 中组句、换序等操作实际引发变化时，冻结玩家移动、转向和组句输入；已有世界效果继续，新句子的效果等待电影黑边完全到位后才生效；先播放带短暂停顿的方框涟漪与星芒，完整展示后再同时出现电影黑边、收起面板并开始镜头矫正；镜头保持原有眼位，不平移、不追随目标，只做小幅朝向矫正（当前上限 6 度），观察约三秒，再恢复朝向与原面板状态。重复同效果、已经到位或受阻而没有新变化时不播放；退出游戏直接执行。
- 拆句、移回词库及清空不播放 cutscene，包括拆句后原冲突句接管效果；世界效果仍按当前有效句正常更新。

## 当前句式与效果

当前登记 36 条句式，由基础句式、定向移动及主语状态修饰组合构成。只接受明确登记的完整句子，其余组合划掉。

| 句式 | 效果 |
| --- | --- |
| 正状态 灯 | 所有场景灯实例开灯，环境进入白天。 |
| 负状态 灯 | 所有场景灯实例关灯，环境进入夜晚。 |
| 灯 move | 所有场景灯实例自由移动；与开关灯独立并存。 |
| 世界 move | 白天加快云，夜晚漂移星空，逐渐朝玩家面向反方向运动。 |
| 门 move | 门框与鱼群整体自由移动。 |
| 门 世界 move | 整体降至地面，拆句暂停，重组继续。 |
| 正状态 世界 | 成立、不划线，无额外事件，也不阻止退出句。 |
| 负状态 世界 | 立即退出应用，编辑器中停止 Play。 |

### 复合句与定向移动

on/off 分别指正状态／负状态。当前只修饰名词，不修饰 move；允许与移动组合，不表示开始／停止移动。定向语序严格为【A B move】，修饰主语时为【on/off A B move】。倒序、重复修饰词、连续 move 当前无效；两个名词直接相连当前无意义。已明确为“成立但无效果”的句子不划线，但不因此将所有未定义组合都判为成立。

| 句式 | 已确认语义 |
| --- | --- |
| on/off 灯 move | 灯开／关与自由移动同时生效。 |
| on/off 门 move | 门的 on/off 状态与整体自由移动同时生效；off 不等于停门移动。 |
| on 世界 move | 执行世界 move。 |
| off 世界 move | 关闭游戏。 |
| 灯 世界 move | 灯降至地面。 |
| 灯 门 move | 一定影响范围内的灯向门周围聚集，目标在一定范围内呈球形／放射状随机分布；到位后不持续硬挤，灯之间保留空间。 |
| 门 灯 move | 门朝最近的一盏灯移动。 |
| 世界 灯 move、世界 门 move | 玩家和地面持续尝试抬升直到拆句；碰到目标／阻挡可暂停实际位移，规则保持有效，目标升高后继续跟随。灯目标须响应最低灯高度的变化。 |
| 灯 灯 move | 允许试作动态聚类：灯朝自己最近的其它灯移动，形成随机聚集，可动态更新目标。 |
| on/off 门 世界 move 等已定义定向移动的主语修饰组合 | on/off 作用于主语名词，同时执行原移动语义，不作为移动否定。对已登记的移动句提供主语状态修饰组合；off 世界组合执行退出。 |

- 词汇影响范围的通用规则以后规范。本轮定向灯行为与最近灯查询先以玩家为中心、有限距离内的活跃灯为对象；默认半径 50 米，可调。聚门目标为围绕门中心 2.5–5 米的随机球形／放射分布，保留分离距离、到位停止，不持续硬挤。灯聚类按最近的其它灯更新目标；门追灯与灯聚类均保留切换余量，避免等距目标间频繁抖动。
- 句子冲突按成立时间处理：先成立者优先，被压制的完整句子降低透明度、不划无效线。复合句任一效果冲突时整句失效，不允许部分生效，也不占用其余通道；撤销赢家后重新按先后接管。同一对象的不同移动模式互斥，相同效果可共存且不叠加。
- 【门 门 move】【世界 世界 move】当前无效、划线：此处只有一个门和一个世界。多灯允许【灯 灯 move】，不把本关单实例限制直接推广为所有同名句无效。
- 门的无句默认形态已确认：有灯光、鱼游动，无雾且无下一关通行权限；撤销状态覆盖后恢复该形态。其它物体的通用默认形态与永久过程结果如何区分，仍属讨论方向；蜡烛仅为讨论例子，不新增词或功能。
- 世界抬升：以目标实体底部作为地面的接近／接触高度；灯取影响范围内最低一盏，范围尚待统一规范。仅向上运动，抵达或受阻后休眠式等待目标高度／障碍变化；目标上升且通路开放时恢复，目标降低不反向拉低地面，拆句停在当前位置。玩家随地面抬升；目标灯和门不因该句被整体绑定抬升，避免目标与地面同速上升、永远追不到。地面与随行玩家均检查上方实体阻挡；无可用目标时等待，目标降低不向下追随。

- 默认【名词 move】为项目所称“布朗运动”：随机初始方向、实际实体碰撞后反弹、拆句悬停。世界移动保留专门的环境表现。
- 定向语序严格为【A B move】；【门 move 世界】不成立。
- 灯、门、世界分别有移动通道；状态与移动可同时存在，但复合句按整句冲突规则处理。
- 普通行走时云延迟跟随实际行进方向；世界移动时朝面向反方向加速，星空同向漂移；撤销世界移动不重置环境位置。
- 灯亮时白色发光，关时渐黑，底色、自发光、镜面反射和点光同步过渡，开灯恢复。
- INTRO 灯为散布的小方块，当前试作统一一个顶点朝下；初始大小与最低尖端离地高度有变化、整体贴近地面；【灯 move】后可以升高。灯与玩家互相穿过，不限制行走，仍可点击收灯；与其它实体保持碰撞反弹。
- 灯在玩家附近动态加载，远处回收实体并暂停运动，本次运行内保留位置、大小和方向；回来按记录恢复，并服从当前开关与移动句。记录不作为跨次运行存档。全局管理器可调分布、加载范围与运行预算，局部点光限额，灯体发光不受点光名额限制。
- X 为临时昼夜调试开关，编辑备注时忽略；预览保持到有效灯规则变化，不因无关拖词或收词重置。

## 鱼门流程

鱼门是通往下一关的独立门框，不是狭长通道：无底座、灰色闭合矩形框、薄底边、门框暗光、不同尺寸的小鱼呈白色柔光，不做多条光束或薄片光幕。

- 首次全局关灯时，在玩家当时面向的高远空中显现。进度保留，后续开关灯不隐藏、不重定位。
- 悬空时鱼主要在框内游动；接近实体门框时提前向框前或框后绕行，避让距离包含鱼身、鱼鳍和摆尾，落地扩散过程中同样避免穿框。点击收门后可组句降门；移动遇实体阻挡暂停，不穿过玩家，门洞触发体不阻挡通行。
- 只有定向降门完成落地才提交落地进度：一次向外扩散的双圈灰白柔光涟漪（一粗一细，细圈稍后跟随），鱼群平滑扩展到门附近的立体范围。自由移动碰地不算完成；拆句、重组或之后移动门不重播。
- 门的状态语义：默认有灯光、鱼游动，无雾且不能进入下一关；完成落地且【on 门】有效时才显示雾并允许进入下一关；【off 门】鱼静止，关闭鱼和门框的灯光，同时关闭雾和下一关通行。撤销状态句后恢复默认形态。
- 雾的外观保持以门洞中心为核心、贴合门框比例的窄长扁椭球三维雾场：左右收窄、前后压扁且保留厚度；中心相对浓，向外逐渐稀疏；三维噪声形成不规则疏密、空隙和外缘凸出，避免明显的完整球面轮廓；内部纹理持续流动变形，雾在空间中缓慢环绕翻卷，不采用平面云纱、整张旋涡或空心球壳。不加落地扬雾。
- 已落地且 on 门有效时，玩家实际穿过门面才进入下一关初始空房间；靠近、关闭状态穿过或悬空 on 门均不传送。房间为约 12×12 米的方形空间，含地面、四墙和基础照明，无谜题。保留同一第一人称控制器、词库、当前组句及面板；开场物体效果在离开后暂停，退出游戏句仍可使用。下一关专属规则与谜题尚未定义。保留的落地进度不因后续移动撤销。

## 实现取值与未定项

以下是可调实现取值，不是跨对象通用设计：

- 灯初始亮；撤销所有状态句后恢复亮。正负并存时先成立者生效、后者淡化，移除前者后接手。
- 行走约 2.3 米触发 move 收词，灯光过渡约 1.2 秒。
- 云跟随延迟约 1.4 秒、转向约 0.4 弧度/秒、世界移动云速倍率 12，星空角速度 3 度/秒。
- 门前方约 42 米、底部离地约 18 米；自由移动约 3.5 米/秒，降落最高速度约 6 米/秒、加减速约 6 米/秒²，无遮挡时约 4 秒落地；收词距离 65 米，涟漪每圈约 2.4 秒、间隔约 0.25 秒、最大半径约 12 米、鱼群扩展约 2.5 秒。
- 后续空间的谜题与正式关卡、概念积累机制、玩家外观与通用语法待设计，不从已有资产或旧版补全。
