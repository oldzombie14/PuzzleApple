# V4 当前设计

当前设计直接维护原段落，不按聊天顺序追加。探索方向和实现取值不视为定稿。Unity 版本：6000.3.9f1。

## 整体方向（探索中）

第一人称探索解谜：在世界中收集符号词，在 Tab 面板组句，以认知改变世界。V4 探索形态、实例与本质／概念的关系，不绑定某一哲学理论。

- 通过多个空间或谜题理解共有概念，避免由单一例子定义概念。
- 拟积累跨关卡复用的概念，用其创造实例；很多具体名词可能只在当地有效，不认定所有名词都清除。
- 动词拟持续跟随玩家，也可能有其它可携带词。分类、词库、世界观和关卡顺序待设计；机制可借鉴物理、化学、数学、音乐等学科。
- 关卡考虑已有能力和概念的依赖，但不等待完整故事定稿。讨论中的例子不是制作清单；旧版等于／本质化的含义不自动继承。

## 当前范围与呈现

先逐步跑通进入正式关卡前的开场小流程，暂不追求高美术质量，也不要求立即展现完整概念积累系统。暂定衔接为起始空间与小谜 → 另一小空间 → 短衔接谜题 → 第一个正式关卡；具体后续内容待用户说明。

- 玩家无实体身体，光点外观暂缓制作；不做草叶，地面只呈草绿色。
- 玩家体验全程无英文，菜单、提示和教学通过符号与动画。文档中的 move 等英文仅为开发标识；缺少正式素材可用 Unity 原生资源占位。
- 黑屏进入界面：中央【正状态 世界】进入，右上角【负状态 世界】退出。主界面符号默认纯白、悬停变灰，无按钮底色；先淡出符号，再淡出黑底并恢复操作。进入世界后右上角退出符号仅在 Tab 面板打开时显示并可点击，正常行走时隐藏；白天默认接近草地色但降低饱和度，镜头朝地面时渐变为近白的微绿，悬停同样为近白微绿；夜晚随夜景主色变化，同样保持低饱和度与明暗层次。主界面与游戏内配色独立。
- 白天低饱和、有光、有高处缓慢移动的云及云影；夜晚无云，冷暗天空与雾、零星高处柔光星星。星星多数暗、少数略明显，以缓慢星芒伸缩闪烁，不铺满天空。
- 云为具有真实离地高度的平面，与天空柔和衔接，无灰边薄膜；云影对应同一云 Alpha，使用原生方向光 Cookie，不在地面另算无关噪声。

## 收词与面板

七词为正状态、负状态、世界、Ground（地面）、move、灯、门。符号统一位于 `Sprites/V4/`，按当前含义命名；地面使用 V2 Light 图案的独立副本 `Floor.png`，运行时词 ID 保持 ground。World 仅用于正／负状态世界，其余原 World 句式使用 Ground。

- 进入场景获得正状态、负状态、世界，Intro 入场自动打开 Tab 面板。Tab 开关左侧面板，保留词库、拖拽组句、拆句、无效句划线、快照与备注；复用布局不表示继承旧玩法。
- 首次平稳直线行走并收 move，不再加入踉跄、左右摇摆或步速顿挫。首步起至收词动画完成禁止世界物体交互，中途停步不解锁。先点灯则收词结束前暂停位移、保留转向。词在飞入结束时入库，不重复收取。
- 瞄准地面点击收 Ground；瞄准发光方块或太阳点击收灯；瞄准点击显现的鱼门收门，沿用眼睛反馈和收词动画。同类词已收集后，瞄准该类物体（包括太阳）显示淡眼睛，仍可点击；点击只让字符在屏幕中央放大并淡出，提示期间隐藏眼睛与准星，符号按背景明暗自动对比，不重复入库、不覆盖首次快照、不冻结移动。
- 普通实体使用统一、固定的收词范围，首次收集与已收集后的提示共用规则；当前实现取视点到命中表面 7 米，具体数值待试玩。门保留远距离特例（当前 65 米）；太阳是天空特例，按可见太阳圆盘的方向识别、不受实体距离限制，夜晚圆盘消失后不响应，前方实体遮挡时不穿透选中。收词范围与句子效果的影响范围分别配置。
- 眼睛居中、140×140，普通准星及收词符号保持已有布局和对比效果。无快照时框内显示左下至右上的对角线，有图时隐藏，保留框线与备注。
- 词的提示保留首次获得时的情境：正状态、负状态共用按快照框约 2:3 比例独立排版的黑底白符号开始界面示意图，符号保持原比例、完整显示，不拉伸或裁切，中央【正状态 世界】作为整体水平、垂直居中，右上角保留较小的【负状态 世界】；世界使用透明背景应用图标，Game.exe 以干净的白色字体重新排版；地面使用不含方块灯且地平线水平的静态画面；灯保留首次收词画面；门使用有留白的正面正交快照，不改变实体尺寸；move 使用预录的第一人称平稳直线行走循环片段。名词默认静态、动词默认动态，其它词默认静态，无法合适表述的词可无提示。
- Tab 面板打开时，3D 视角只做轻微上下俯仰晃动，保持水平方向不偏转；关闭面板时接续当前朝向。
- 开关 Tab 不等于拆句，不能仅因面板关闭而停止有效移动。
- 快照关闭按钮使用负状态（OFF）符号。快照打开后自动聚焦备注框，显示原生闪烁输入光标；备注暂限单行，Enter 与保存按钮均可保存。组句左侧拖拽圆点默认隐藏，鼠标进入覆盖整句、左侧留白与圆点的连续矩形区域时淡入，移出淡出；拖动期间保持显示。

### 句子反馈与 Intro 演出

- 加减字直接更新句子，不再擦除后重写。反馈出现在 Tab 中对应句子周围：成立且实际产生新表现时为方框涟漪加菱形星芒，星芒使用贴图素材与粒子；成立但无明确新表现（停滞、已到位或处于指定距离范围）时只有较弱方框涟漪；冲突句为较弱方框涟漪并降低透明度，不触发星芒或演出；不成立保留划线。
- Intro 中组句、换序等操作实际引发变化时，冻结玩家移动、转向和组句输入；已有世界效果继续，新句子的效果等待电影黑边完全到位后才生效；先播放带短暂停顿的方框涟漪与星芒，完整展示后再同时出现电影黑边、收起面板并开始镜头矫正；镜头保持原有眼位，不平移；转向与轻微追随按各句式配置；Ground move 演出保持水平方向，抬头至可见天空的视角，已抬得更高则保留当前仰角，短暂停留观察，保留演出结束时的朝向并恢复操作与原面板状态；若已存在因光源关闭而暂停的【灯 move】，新增【正状态 灯】时先给开启句带星涟漪，再给移动句带星涟漪，只使用移动句镜头，两句效果均生效。新效果开始后可按 Tab 中断镜头并返回组句，便于在变化途中拆句。重复同效果、已经到位或受阻而没有新变化时不播放；退出请求先淡入较宽松的纯黑无边框确认框，符号尺寸保持不变，只显示正状态（ON）与负状态（OFF）符号；ON 确认后淡入黑屏再退出应用，OFF 仅关闭弹窗并恢复原操作状态。弹窗阻止背景点击、移动和组句；取消不拆除退出句，不因编辑其他句子反复弹出，拆开后重新组成退出句可再次请求确认。右上角退出与组句共用此流程。
- 只有成立且能产生世界表现的完整句式才绑定独立演出配置；退出句和无表现的【正状态 世界】不绑定，不按动词／效果优先级选镜头。例如【Ground move】前接灯后，使用【灯 Ground move】配置；状态与移动需分成两句，不支持【正状态 灯 move】。仍只在实际新增可见变化时演出，重复效果不重播。组句仅支持整组前接／后接，不支持直接插入中间。
- 镜头要求：所有 cutscene 全程保持 roll 为 0，包括进入、跟随、瞬切和结束；不设转向角度修正上限。演出结束或按 Tab 中断时保留当前朝向，不转回演出前；玩家从该朝向继续操作。【正状态 灯】与【负状态 灯】镜头对称：保持 yaw、平滑调整 pitch，地平线位于画面下三分之一，不跟随；【灯 move】仅以 pitch 对准灯群、不跟随。【门 move】对准并轻微跟随门；门状态句和降门只对准、不跟随，角度很大时瞬切。【Ground move】保持 yaw，天空约占三分之二，已抬得更高则保留；两种 Ground 定向移动均保持 yaw、地平线下三分之一、不跟随。【灯 Ground move】高低灯群均放在画面下三分之一，以 pitch 向下跟随下降过程，保持 yaw；【灯 门 move】对准门，偏离很大可瞬切；【灯 灯 move】对准灯群。取景与转速具体数值为待试玩的实现取值。
- 拆句、移回词库及清空不播放 cutscene，包括拆句后原冲突句接管效果；世界效果仍按当前有效句正常更新。

## 悬空符号提示（试作）

- 暂用悬浮在远处、垂直于地面的符号阵列，不制作石碑。显现时记录玩家背后的世界方位；此后保持该方位与显示距离，走近不会放大，转开视线就看不到，转回原方位可再看到。
- 初始三条为【负状态 世界】【灯 move】【灯 Ground move】。对应有效操作实际应用后划掉；看到提示之前做过的操作也计入。冲突失效句不计入。
- 初始三条未全部完成时，白天与夜晚都显示，夜晚使用独立的低亮度冷色和透明度，保持淡淡融入天空的效果。三条完成后整组淡出，换成【负状态 灯】；仅剩这条时只在白天显示，入夜前先淡出，再开始环境变暗。执行该操作后提示淡去；先于提示发生的关灯也计入，四项都完成后不再显示。
- 四项提示完成进度自动保存到本地，下次 Play／启动恢复，不保存词库、组句或世界状态。进入世界后组退出句或点击右上角退出按钮，在打开确认框时即保存【负状态 世界】完成，选择 ON 退出或 OFF 取消都保留；主菜单退出不计入。
- 测试快捷键 X 删除本地天空提示完成记录并立即移除划线，恢复第一组提示；不清除词库、组句或世界状态。正在备注输入框中打字时不响应。当前持续生效的句子不会因无关操作重新记入，撤销后再次生效才重新记录。
- 方块灯首次生成后，才在玩家当时朝向的背后渐显；玩家可以暂时不发现，提示不会主动转到眼前。完成记录及夜晚隐藏规则保持有效。

## 当前句式与效果

当前登记 16 条句式：6 条独立状态句与 10 条基础／定向移动句。暂不允许正／负状态修饰移动句。只接受明确登记的完整句子，其余组合划掉。

| 句式 | 效果 |
| --- | --- |
| 正状态 灯 | 所有场景灯实例开灯，环境进入白天。 |
| 负状态 灯 | 所有场景灯实例关灯，环境进入夜晚。 |
| 灯 move | 所有场景灯实例自由移动；状态句与移动句可并存；完全关闭时暂停移动。 |
| Ground move | 白天加快云，夜晚漂移星空，逐渐朝玩家面向反方向运动。 |
| 门 move | 门框与鱼群整体自由移动。 |
| 门 Ground move | 整体降至地面，拆句暂停，重组继续。 |
| 正状态 世界 | 成立、不划线，无额外事件，也不阻止退出句。 |
| 负状态 世界 | 请求退出确认；ON 淡出退出，OFF 关闭弹窗。编辑器中确认退出会停止 Play。 |

### 独立状态句与定向移动

on/off 分别指正状态／负状态。状态只允许独立的【on/off 名词】句式，暂不接受【on/off 名词 move】或【on/off A B move】。可将【正状态 灯】与【灯 Ground move】分成两句，同时开灯和降灯；两句分别演出、可分别拆除，互不占用对方的状态／移动通道；光源完全关闭时只有开启光源可推动新变化，其它含光源的移动句保持成立但暂停效果，开启后恢复。定向语序严格为【A B move】。倒序、重复修饰词、连续 move 当前无效；两个名词直接相连当前无意义。已明确为“成立但无效果”的句子不划线，但不因此将所有未定义组合都判为成立。

| 句式 | 已确认语义 |
| --- | --- |
| 灯 Ground move | 灯降至地面。 |
| 灯 门 move | 一定影响范围内的灯向门周围聚集，目标在一定范围内呈球形／放射状随机分布；到位后不持续硬挤，灯之间保留空间。 |
| 门 灯 move | 门朝最近的一盏灯移动；灯已靠近门框范围时只给弱涟漪、不演出；当前阈值为距门框整体包围范围约 1.4 米，灯体外缘也计入，待试玩调整。 |
| Ground 灯 move、Ground 门 move | 玩家和地面持续尝试抬升直到拆句；碰到目标／阻挡可暂停实际位移，规则保持有效，目标升高后继续跟随。灯目标取玩家视野内最低一盏，并响应高度变化。 |
| 灯 灯 move | 允许试作动态聚类：灯朝自己最近的其它灯移动，形成随机聚集，可动态更新目标。 |

- 词汇影响范围的通用规则以后规范。本轮定向灯行为与最近灯查询先以玩家为中心、有限距离内的活跃灯为对象；默认半径 50 米，可调。聚门目标为围绕门中心 2.5–5 米的随机球形／放射分布，保留分离距离、到位停止，不持续硬挤。灯聚类按最近的其它灯更新目标，聚集速度比其它定向灯移动更慢；门追灯与灯聚类均保留切换余量，避免等距目标间频繁抖动。
- 句子冲突按成立时间处理：先成立者优先，被压制的完整句子降低透明度、不划无效线。撤销赢家后重新按先后接管。同一对象的不同移动模式互斥，相同效果可共存且不叠加。
- 【门 门 move】【Ground Ground move】当前无效、划线：此处只有一个门和一片地面。多灯允许【灯 灯 move】，不把本关单实例限制直接推广为所有同名句无效。
- 拆句停止该句持续推动的变化，保留拆除瞬间的实际状态，不恢复初始值；包括移动位置、灯亮度、昼夜混合及门雾显隐的中间值。记录灯的当前开／关／中间状态与连续亮度，目标开关单独保存；相同或相反状态句从当前值继续，不瞬切。若被压制的句子接管，则由接管句继续推动当前状态。保留仅限本次运行，不新增世界存档。
- 地面抬升：以目标实体底部作为地面的接近／接触高度；灯取玩家视野与影响范围内最低一盏，范围尚待统一规范。仅向上运动，抵达或受阻后休眠式等待目标高度／障碍变化；目标上升且通路开放时恢复，目标降低不反向拉低地面，拆句停在当前位置。玩家随地面抬升；目标灯和门不因该句被整体绑定抬升，避免目标与地面同速上升、永远追不到。已落地的门可阻挡地面上升，升向门时中间的灯同样可阻挡；地面与随行玩家均检查上方实体阻挡；无可用目标时等待，目标降低不向下追随。目标或阻挡已在地面附近时只给弱涟漪、不演出，近处阈值暂为 0.5 米。

- 默认【名词 move】为项目所称“布朗运动”：随机初始方向、实际实体碰撞后反弹、拆句悬停。门已贴地时，自由移动起步方向必须向上，避免向下顶地而看不出变化。世界移动保留专门的环境表现。
- 定向语序严格为【A B move】；【门 move Ground】不成立。
- 灯、门、Ground 分别有移动通道；独立状态句与移动句可以同时存在。完全关闭的光源不能移动，也不能作为门／地面移动的有效目标；这些句子只给弱涟漪、不演出，开启光源后已有移动规则恢复。正在变暗但尚未完全关闭的光源仍可运动，拆句保留中间亮度。
- 普通行走时云延迟跟随实际行进方向；世界移动时朝面向反方向加速，星空同向漂移；撤销世界移动不重置环境位置。
- 灯亮时白色发光，关时渐黑，底色、自发光、镜面反射和点光同步过渡。开关使用对称节奏：环境先开始变亮／变暗，灯随后以较慢渐变重叠过渡；关灯时按悬空提示的当前阶段处理显隐。
- INTRO 灯为散布的小方块，当前试作统一一个顶点朝下；初始大小与最低尖端离地高度有变化、整体贴近地面；【灯 move】后可以升高。玩家行走加载新区域时，若自由移动已生效，首次出现的新灯从贴近地面处开始向上运动；回到旧区域仍恢复原记录，不重置旧灯高度。灯与玩家互相穿过，不限制行走，仍可点击收灯；与其它实体保持碰撞反弹。
- 开场保留太阳，方块灯延后出现：先收地面再收 move 时，等 move 收词动画结束才生成；先收 move 再收地面时，收地面后还需实际走一小段距离。首次灯生成在远处，玩家触发时附近保留无灯区域；不依赖是否已收灯词，不新增地板。步行距离与首次无灯区域大小为可调试玩取值。
- 灯在玩家附近动态加载，首次及后续加载均逐个错开、柔和淡入，灯体与局部照明同步过渡；远处回收实体并暂停运动，本次运行内保留位置、大小和方向；回来按记录恢复，并服从当前开关与移动句。记录不作为跨次运行存档。全局管理器可调分布、加载范围与运行预算，局部点光限额，灯体发光不受点光名额限制。

## 鱼门流程

鱼门是通往下一关的独立门框，不是狭长通道：无底座、灰色闭合矩形框、薄底边、门框暗光、不同尺寸的小鱼呈白色柔光，不做多条光束或薄片光幕。

- 首次全局关灯时，在玩家当时面向的高远空中显现，门始终保持竖直，并持续绕竖轴朝向玩家相机（本轮试作），不只在显现时对齐。显现改为散开的粒子聚拢到门框与鱼群表面，实体渐显，完成后才可收词；不再突然出现。进度保留，后续开关灯不隐藏、不重定位。
- 悬空时鱼主要在框内游动；接近实体门框时提前向框前或框后绕行，避让距离包含鱼身、鱼鳍和摆尾，落地扩散过程中同样避免穿框。点击收门后可组句降门；移动遇实体阻挡暂停，不穿过玩家，门洞触发体不阻挡通行。
- 自由移动的门碰地只反弹，不提交落地；拆除该自由移动句时，若门在贴地容错范围内，则贴合地面并提交进度，距离较远则原地悬停。定向降门仍在触地时提交进度，并忽略灯的碰撞，保留玩家与其它实体阻挡。首次完成后播放一次向外扩散的双圈灰白柔光涟漪，鱼群平滑扩展到门附近的立体范围；进度保留，不重复播放。
- 门的状态语义：仅开／关两种状态，初始即开启（有灯光、鱼游动），悬空时无雾且不能进入下一关；完成落地且门处于开启状态时显示雾并允许进入下一关；【off 门】鱼静止，鱼和门框的灯光渐暗，同时关闭下一关通行并开始淡出雾。撤销状态句后保留开关结果，渐变中的门灯与雾停留在当前亮度／显隐值；再次施加状态句可继续渐变。之后首次触地等独立事件仍可触发后续表现。
- 雾的外观保持以门洞中心为核心、贴合门框比例的窄长扁椭球三维雾场：左右收窄、前后压扁且保留厚度；中心相对浓，向外逐渐稀疏；三维噪声形成不规则疏密、空隙和外缘凸出，避免明显的完整球面轮廓；内部纹理持续流动变形，雾在空间中缓慢环绕翻卷，不采用平面云纱、整张旋涡或空心球壳。不加落地扬雾。
- 已落地且门保持开启状态时，玩家实际穿过门面才进入 ChapterI 中转房间；靠近、关闭状态穿过或悬空 on 门均不传送。常驻系统持有同一第一人称控制器、词库、当前组句及面板；场景管理器在黑底右下角进度条下异步加载目标内容，安排玩家到达后卸载 Intro，退出游戏句仍可使用。独立运行内容场景时自动加载同一套系统。保留的落地进度不因后续移动撤销。

## ChapterI：镜子、走廊与花房

- 已确认：镜子在 Unity 中按中转场景玩家出生点与初始朝向独立摆放，位于玩家正后方；Blender 中隐藏的镜子不作为布局依据。镜子具有实时反射，沿用瞄准、点击与收词动画，动画结束获得跨场景保留的核心词 mirror，随后方盒像 UV 展开般打开，通向走廊。mirror 使用先前镜子图标；词条快照使用预先拍好的固定正面静态图，完整保留镜框、四周留白及镜面反射，不使用点击时的玩家视角；本轮不新增语法或解谜规则。
- 已确认：展开后镜子位于走廊身后的墙上。展台不属于中转房间。后墙、镜子和地板固定，前墙、两侧墙与顶板绕边展开，随后缓慢沉入地面以下，不留下白色墙板；展开期间不限制玩家视角。展台位于走廊远端，具体展开节奏与布局观感待试玩。
- 玩家视角需高于此前版本；当前 ChapterI 与花房眼高试设 2 米。展台比例以玩家正常眼高能看清柜内展品为准；中转房间、走廊与花房墙体暂用无纹理纯白材质，地面使用中性浅灰，不带绿色。灯光在 Unity 中独立设置，参考 V3 的中性白光与灰色阴影风格，不导入 Blender 灯光布局。走廊采用 V3 通道 shader 的连续明暗过渡，减少分散光斑，展柜保留一处局部重点照明。
- 已确认：补齐走廊缺墙；最初两幅画框按 Blender 的布局关系放在靠近玩家的入口端。左右画框尺寸相同，左侧保留下沿；以画框为尺寸基准扩大花房洞口，不缩小画框适配花房。左侧画框实时显示花房，玩家在门外移动时内部透视随之变化。实际跨过画框进入独立花房 Scene，从原入口返回走廊；往返保留词库、面板与本次展开状态。
- 花房沿用 Blender 悬浮花群构成，加入轻缓漂浮与摆动，保留地面通行空间。花房专属相机 shader 留待后续单独指定；届时只在玩家进入花房时启用，离开恢复，不影响走廊。本轮尚未制作该效果。

## 词汇作用域

后续部分词汇仅在当前场景有效，离开时消失；其余词汇随玩家保留。当前七词尚未指定为临时词，继续全部保留。实现预留场景级临时词清单；暂定清理含临时词的整句，其余词仍保留在词库，不自动拼接剩余字符产生新效果；临时词的快照与备注一并清理，重访可以重新收取。具体词汇分配和重访世界状态尚未设计。

## 实现取值与未定项

以下是可调实现取值，不是跨对象通用设计：

- 灯初始亮；状态句开关从当前亮度渐变。是否有新效果按实际亮度及环境混合判断，中间状态不等同于已开或已关；完整变暗后才视为首次全局关灯并显现门。
- 行走约 2.3 米触发 move 收词；环境过渡约 2 秒，环境推进约五分之一后开始约 2.4 秒的灯光渐变。门灯渐变约 1.8 秒，自由移动门拆句贴地容错暂为 0.5 米。以上节奏待试玩。
- 云跟随延迟约 1.4 秒、转向约 0.4 弧度/秒、世界移动云速倍率 12；星空使用同一漂移方向与加速进度，依据当前观察方向和云层高度匹配画面中心的角速度，不再使用独立的固定角速度。平面云和球面星空在画面边缘仍有投影差异。
- 门前方约 42 米、底部离地约 18 米；自由移动约 3.5 米/秒，降落最高速度约 6 米/秒、加减速约 6 米/秒²，无遮挡时约 4 秒落地；收词距离 65 米，涟漪每圈约 2.4 秒、间隔约 0.25 秒、最大半径约 12 米、鱼群扩展约 2.5 秒。
- 后续空间的谜题与正式关卡、概念积累机制、玩家外观与通用语法待设计，不从已有资产或旧版补全。
