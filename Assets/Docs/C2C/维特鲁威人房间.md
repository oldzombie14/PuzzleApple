## 0. 一句话

照花房的结构，在主展廊新增一组「一侧挂画、一侧是房间」：右墙挂维特鲁威人原画，左墙是通往维特鲁威人房间的活画框。房间最深处的墙前站着维特鲁威人，人物背后的墙面上有两套机关：**用镜子反射画出正方形**、**用绕肚脐旋转的发光球画出圆**。本轮只做两个谜题各自的成立状态，**暂无过关判定**（房间还没设计完）。

另外两件同在 Chapter I、但不在这个房间里的事：**入口镜子的 mirror 行为**（§6）和**天平与展柜的美术调整**（§7）。

## 2. 已定设计【已定】

### 2.1 布局
1. Chapter I 在花房之外再加一组「画框 + 房间」，**结构和花房一样**：走廊一侧挂画，另一侧是房间，房间内容的主题对应走廊上这幅画。挂的画是**维特鲁威人**（`Assets/Docs/TMP/维特鲁威人.png`）。
2. Chapter I 左侧的房间本质上都是**特殊 portal**，不是走进去的普通房间。本轮把这些房间和走廊的句子作用范围**隔离**（见 §3.4）。
3. 房间最深处放维特鲁威人 3D 模型（`Assets/Docs/TMP/vitruvian_15kfbx.fbx`）。
4. 房间左右墙各 2 个画框，对称、等大，比外部画框小一个尺寸，比例以花的画为准。**这 4 幅画本轮留空**。
5. 先把场景摆好。

### 2.2 正方形谜题（在人物背部）
1. 光源在身体背后、**耻骨（裆）高度**，也就是正方形的中心，**竖直向上**打，这段光被身体挡住。**发射源算 light，但固定不动**：只受 on／off light 影响，`light move` 不移动它。
2. 头顶上方有一个**分光镜**，把光分成左右两束 → 上面两个角的镜子把光往下打 → 下面两个角的镜子把光往里打 → 两束光在**两脚之间的空处**汇合，画成正方形。
3. 初始只有**左侧那一组角镜**（左上、左下）加分光镜。`mirror mirror`（持续句）把左侧一组镜像到右侧，变成四面。
4. `mirror move`：四面镜子各绕**垂直于墙面的轴**摆动，以 45° 为中心，摆幅约 ±30°，单程 6–8 秒。左右两侧镜像同步，只有一个角度能让四面同时对上。
5. 玩家要**带一点预判**地停下句子。停下时离 45° 在约 3° 以内，镜子回弹吸附到正确角度。**不加其它前摇**。
6. **拆句停止和 `no move` 等效**，两种停下都允许吸附（`no move` 不是暂停游戏）。

### 2.3 圆形谜题（也在人物背部）
1. 圆心是**肚脐**（用户确认中轴是肚脐，不是裆。达·芬奇原画里圆心是肚脐，正方形的中心在耻骨附近，两者都在中轴线上但不重合）。
2. 一根杆拉着一个球，球**初始不发光**。
3. 用 `on light`，或**把 light 拖到球上**，球才点亮。这个房间**打开拖拽实例化的区域开关**，供用户测试。
4. 点亮后 `light move`：只要句子没拆，球就一直绕肚脐转，带尾迹，形成圆。
5. 球的初始位置**不在正中**（在正中玩家可能以为是装饰）。
6. ~~允许房间内和走廊的灯被一起控制~~ → 已改：本轮房间与走廊**隔离**（§2.1 第 2 条）。

### 2.4 通过条件
- 设计方向：正方形和圆**都处于成立状态**，但不要求同时刻完成。
- **本轮暂无过关判定**（房间没设计完），只做两者各自的成立状态和反馈。

### 2.5 入口镜子（主展廊）
1. 指玩家进入 Chapter I 后背后的那面镜子（`Arrival mirror`），也就是回开阔地的通道。
2. `mirror mirror` 把它镜像到**天平背后的墙**上。
3. `mirror move`：镜子连同它的通道在墙面上**随机运动**，**不限制高度**，允许停在够不着的地方。
4. 副本刚出现时被展柜挡住、要先 `mirror move` 挪开才能进去：**保留**。
5. 方盒未展开时，`mirror mirror` **可以成立**，副本出现在方盒对面的盒壁上；`on world` 展开方盒后，副本随盒壁没入地下，这句**自动消失**（词回词库）。
6. `mirror X` 是**持续句**（和 `light X` 一样），句子成立期间持续生效。

### 2.6 天平与展柜
1. 远处的天平和展柜要**调大**。
2. 天平**右侧放羽毛**（古埃及《亡灵书》称心仪式：一端是死者的心脏，一端是真理女神玛阿特的羽毛）。
3. 左侧每完成一个关卡出现一个物件，压低一点左侧；全部完成后天平持平。
4. **本轮只调美术**；逻辑写进文档，标为暂不开发（§7.3）。

## 3. 房间布置【建议】（批次 5）

### 3.1 位置和尺寸
- 照花房的结构新开一组：**左墙（z=−10.57）开活画框通往房间，右墙（z=+10.57）正对位置挂维特鲁威人原画**。
- 沿 X 的位置建议 **x=0**（花房 x=20 与展柜 x=−13.7 之间，正好在 x=0 的天花灯下），可调；画框与 `Left wall before frame` 需要切开对应洞口。
- 房间位于左墙画框后方，沿 −Z 延伸。入口照花房做一套 9 级踏步（复制 `Gallery entrance tread 1–9`，x 改为新画框位置），画框底边离展廊地面约 1.59 米，房间地面与画框下沿齐平，两端几何直接相接（同花房）。
- 建议内部尺寸 **18（X）× 16（高）× 30（Z）米**，房间中轴与画框中心对齐：
  - 正方形边长 H 取 **10 米**（见 §3.3），圆半径约 0.607 H ≈ 6.1 米，圆顶约 12.1 米高，16 米层高留得出余量。
  - 18 米宽给圆两侧各留约 3 米。
  - 30 米进深：前 22 米挂 4 幅画，最深处约 8 米给人物和机关。
- 所有尺寸做成搭建脚本或 Inspector 参数，方便用户在场景里直接拉。

### 3.2 走廊上的画与画框【已定：和花房结构一样】
- **右墙挂画**：维特鲁威人原画（png），画框与 `Right painting` 同款同尺寸（8.6 × 12.21），上方同款画灯（`Right painting spotlight` 的做法），参与 on／off light。不做渐隐。
- **左墙活画框**：和 `Living frame to ChapterI_Garden` 一样，框里直接看到真实房间，玩家从顶级踏步跳过框槛往返。从走廊看进去，深处的人物、方形光路和圆就是这幅画的立体版本。
- png 是 435 × 459 近似方形，画框是竖幅（8.6 × 12.21）。**默认不拉伸**：图居中、等比放满宽度，上下用接近纸色的衬底补齐。【待确认】如果想裁成竖幅或改画框比例，请告诉 Astra。

### 3.3 维特鲁威人模型
- 模型：`vitruvian_15kfbx.fbx`（用户指定）。它应该是两种姿势叠合的人体，和原画一致。如果导入后发现是单一姿势，先停下问用户（Blender 文件里另有拆好的 `Vitruvian_TPose_Split`／`Vitruvian_StarPose_Split`）。
- **朝向**：面朝房间入口（−Z），背靠深处墙，**身体离墙约 0.6 米**。机关都在这面墙上（「人物背部」），从正面看过去，光路和圆在人物周围露出来，被身体挡住的那段光（裆 → 头顶）看不见。
- **尺寸**：按模型实际量。正方形边长 H = 头顶到脚底的高度 = 平举双臂的指尖距离（原画如此，Astra 量模型时核对两者是否接近，取平均）。建议把 H 缩放到 10 米。
- **关键点**（以脚底中心为原点，在墙面平面内）：
  - 正方形：中心约 (0, H/2)（裆），四角 (±H/2, 0)、(±H/2, H)。
  - 圆：圆心在肚脐，按模型量肚脐高度 N（原画约 0.607 H），半径 R = N（圆的底边也贴脚底）。
- **材质**：人物用 World Surface 纯白哑光 + 细黑边，像石膏像。房间里唯一发光的东西应该是光束、发光的球和灯，人物本身不发光。

### 3.4 房间表面
- **默认**：World Surface 纯白哑光 + 细黑边（和 Intro 各房间一致）。理由：白底黑线本身就像达·芬奇的手稿纸面，光束和发光球在上面最清楚。
- 深处墙上**不刻**方和圆的提示线（已定：走廊上的原画已经是提示）。
- 照明：天花灯沿用 Room Light Style 的统一补光规则，和主展廊一致；从展廊看进去和走进房间后亮度基本一致（同 Intro 通道的调法）。
- **作用范围隔离【已定】**：本房间是特殊 portal，和主展廊**互不影响**。在走廊里组的句子不作用到房间里，在房间里组的句子不作用到走廊，**即使看得见也一样**（这是对「所在空间 + 视野方向」规则的例外）。实现上给 Chapter I 左侧的 portal 房间加一个「隔离」标记，范围计算遇到它就只取玩家所在的那一侧。花房同样是左侧 portal，【待确认】是否一并隔离，默认**一并隔离**（用户说的是「左侧的房间都是特殊 portal」）。

### 3.5 四幅画（留空）
- 左右墙各 2 幅，对称、等大。外部画框 8.6 × 12.21，**小一个尺寸建议取 0.7 倍：6.0 × 8.5 米**，比例与花画一致。
- 画布本轮放**空白纸色画布**，画框用和外部画框同一款（`PictureFrame_AntiqueGold`）。画布物体按 `PaintingCanvas` 的结构摆（画框 + 画布 Quad），方便以后接画间传递（project-files 的 `painting-room` 草稿，**本轮不接入**）。
- 每幅画上方一盏和主展廊同款的画灯（`Gallery wall light` 预制体），参与 on／off light。
- **画灯有轴【已定】**：`light move` 时画灯绕安装轴**上下摆动**（俯仰来回），建议摆幅 ±20°、单程约 3 秒，光斑在画面上上下扫；停下时停在当前角度。

## 4. 正方形谜题【建议】（批次 7）

### 4.1 几何
在深处墙前的「机关平面」上（墙面前约 0.2 米，人物身后约 0.4 米）。坐标同 §3.3。

```
        左上镜 ◄──── 分光镜 ────► 右上镜(镜像)
          │            ▲             │
          │            │ (被身体挡住) │
          ▼            │             ▼
          │          光源(裆)         │
          │                          │
        左下镜 ────►  汇合点  ◄──── 右下镜(镜像)
                    (两脚之间)
```

| 部件 | 位置 | 说明 |
|---|---|---|
| 光源 | (0, H/2) | 固定不动，竖直向上发射；算 light，受 on／off light 控制，初始亮着【建议】 |
| 分光镜 | (0, H)，头顶正上方 | 固定的「∧」形双面镜，把光分到左右，水平射出 |
| 左上镜 / 左下镜 | (−H/2, H) / (−H/2, 0) | 初始存在，正确角度时分别把光折向下、向内 |
| 右上镜 / 右下镜 | (+H/2, H) / (+H/2, 0) | `mirror mirror` 镜像出来的副本 |
| 汇合点 | (0, 0) 附近 | 从正面看在两脚之间的空处 |

- 底边光束贴着脚底高度。光束在机关平面上、人物身后，**物理上不会被脚挡住**；从正面看光在两脚之间汇合。底边可整体抬高 0.1 米防止和地面 Z-fighting。
- 分光镜在人物中轴（对称面）上，所以 `mirror mirror` 对它**不复制**（见 mirror 规则 §3.4）。

### 4.2 光路
- 光路实时计算：从光源出发做射线，遇到镜面按反射定律折返，最多 8 次反射，打到墙或其他物体就停，终点留一个小光斑。
- 镜子不在正确角度时，光会按实际反射方向射偏，玩家能看到它扫来扫去、几次差点闭合。
- 角度误差 δ 让出射偏 2δ。10 米边长下 3° 误差约偏 1 米，会明显打不中下一面镜子，这正是需要吸附的原因。
- 美术：中性白 HDR 细光束（宽约 3 厘米），轻微 Bloom，和现有灯体发光同一套（WorldGlow／Bloom）。不加颜色。光斑用小号双圈涟漪的静态版。

### 4.3 镜子
- 外观：细长镜板，长约 1.2 米、伸出墙面约 0.3 米、厚约 0.05 米，绕**垂直于墙面的轴**转。背面和边框用 World Surface，反射面复用 `Arrival mirror` 的镜面材质，不另做新风格。
- 「角度」定义：镜面与正确朝向的夹角，正确时为 45°（镜面垂直于该角的对角线、朝向正方形中心）。

### 4.4 `mirror move` 的摆动【已定参数 + 建议细节】
- 每面镜子以 45° 为中心摆动：θ(t) = 45° + A·sin(φ)，**A = 30°，单程 7 秒（可调 6–8）**，用正弦（两端慢、中间快）。
- **左右镜像同步**：副本的角度永远是原件的镜像（mirror 规则「副本始终是原件的镜像」），不用单独写同步逻辑。
- 上下两面镜子同相位，所以每次经过 45° 时四面同时对上，大约每 7 秒有一次机会。【已定：先按这个】不故意错开，但保留 `bottomPhaseOffset`、`bottomPeriodScale` 两个字段，默认 0 和 1。
- 起摆：句子成立时从镜子当前角度接着摆（计算出对应相位），不跳变。

### 4.5 停下与吸附【已定】
- 句子停下（拆句、`no move` 冻结、或者句号机制下把句号拖走，三者等效），镜子停在当前角度。
- 若此时 |θ − 45°| ≤ **3°（可调）**，四面一起**回弹吸附**到 45°：0.35 秒、带一点点过冲的弹簧曲线，吸附完成的一刻光路闭合。
- 超过 3° 就停在原处，光路断开。玩家要重新组 `mirror move` 再来。
- 不加其它前摇（不减速、不闪烁提示）。
- 再次成立 `mirror move`（或解除 `no move`）时，从当前角度起摆，吸附状态解除。起摆方向见 §4.4 和句号文档「运动的暂停与继续」（已定，沿用暂停时的方向与相位）。

### 4.6 `mirror mirror` 与方形
- 初始只有左侧两面，光过分光镜后右边那束直接打在右墙上，方形只画一半。
- `mirror mirror` 成立：右侧两面以副本出现（出现方式见 mirror 规则 §4），立刻参与光路。
- `mirror mirror` 拆掉：副本消失，方形断开。所以玩家必须保持 `mirror mirror` 成立，同时停下 `mirror move`。这是这个谜题的核心难点，**不要自动帮玩家保持**。

### 4.7 成立判定
`SquareSolved` = 四面镜子都存在 && 都在 45°（±0.5°）&& 光源亮 && 两束光在汇合点交汇（射线实测，不只看角度）。`off light` 关掉光源时光路消失、不成立。
- 成立时：光路整体亮度提升一档，汇合点放一次双圈涟漪（和碰撞涟漪同参数）。
- 成立状态是**实时的**，任何一个条件失去就不成立（例如重新 `mirror move`、拆掉 `mirror mirror`）。

**光源与 light【已定】**：只有发射源算 light（可瞄准收 light、受 on／off light 控制），它固定在原位，`light move` 不移动它。光束和光斑本身不算 light。

### 4.8 验收（批次 7）

- [x] 在 ±3° 外停下：停在原角度，不吸附，光路断开。

## 5. 圆形谜题【建议】（批次 8）

### 5.1 结构
- 肚脐处一个小枢轴，一根细杆（黑色细线外观，粗约 2 厘米）连到球。杆长 = R（§3.3），球半径约 0.25 米。
- 枢轴在机关平面上，杆和球也在机关平面上，在人物身后转。
- 初始：球**不在正中**（已定，避免看起来像装饰）。建议放在约 **4 点钟方向**（右下，偏离中轴 60°以上，角度可调），不发光，World Surface 白色哑光 + 细黑边。

### 5.2 点亮
- `on light`（作用范围内）：球和房间里其他灯一起亮；走廊的灯不受影响（房间与走廊隔离）。
- **把 light 拖到球上**：这个房间的根物体挂 `WorldDropRegion`，打开 light。松手时准星射线若**命中球**，就直接点亮球（词照现有拖拽逻辑归库），**不弹形状选择框、不生成新灯**；没命中球就走正常的形状选择和生成。
- 点亮表现：沿用 on light 的渐亮时长，中性白 HDR，和室外灯同一套发光。
- 点亮后，球就是这个空间里的一个 light：`off light` 会让它渐灭，light 的收词、已知词反馈照常。
- 点亮的球**不能**被右键回收（它不是玩家生成的实例，已定）；`off light` 可以关掉它。

### 5.3 `light move`
- 有轴就规律运动（用户的规则：有轴才规律往复／旋转，无约束才布朗运动）。球被杆约束，所以 `light move` = **绕肚脐匀速旋转**，一圈 **8 秒（可调）**，方向逆时针（正面看）。
- 球不亮时不动（V5 规则：light 指当前发光的光源）。熄灭后原地暂停，重新点亮且句子还在则继续。
- 尾迹：中性白 HDR 细线（宽约 4 厘米），**尾迹长度 = 一整圈**，所以转满一圈后整个圆持续可见、首尾相接。
- 停下（拆句、拖走句号、`no move`、熄灭）：球停在原处，尾迹在 **1.5 秒内淡掉**（已定：句子拆了就没有圆；`no move` 也一样淡、一样不成立，之后若和其他谜题冲突再改）。
- 和 `light move` 同时作用到房间里的其他灯（例如拖进来的自建灯）：它们照现有规则运动，互不影响。

### 5.4 成立判定
`CircleSolved` = 球亮着 && `light move` 正在驱动球 && 本次连续运动已经转满 360°。
- 刚转满一圈时：整个圆环亮度提升一档 + 一次双圈涟漪。
- 停下（含 `no move`）或熄灭立即不成立。

### 5.5 通过判定【暂不开发】
本房间还没设计完，**本轮不实现过关判定**，只实现方、圆各自的成立状态、反馈和事件（`SquareChanged`、`CircleChanged`）。下面是以后的设计方向，供参考：

`VitruvianSolved` = `SquareSolved && CircleSolved` 同时成立，**持续 0.5 秒**。
- 一个可以先完成另一个后完成，只要某一刻两者同时成立即可（例如：方形吸附好并保持 `mirror mirror`，再点亮球、成立 `light move`）。
- 两条句子的通道：`mirror move` 是 `mirror.motion`、`light move` 是 `light.motion`，互不冲突，可以同时存在。
- 通过时：方和圆同时脉冲一次，发出 `Solved` 事件，**一次性记住**（本次运行内），之后再破坏方或圆不撤销。
- 通过后发生什么待房间设计完再定，以后接天平（§7.3）。

### 5.6 验收（批次 8）
- [x] 球初始不亮；`light move` 时不动。
- [x] 球初始不在正中（约 4 点钟方向）。
- [x] `on light` 点亮球（房间内的灯一起亮，走廊不受影响）；`off light` 熄灭，熄灭后暂停。

## 6. 入口镜子（主展廊）【建议】（批次 6 的一部分，详见 mirror 规则）

### 6.1 `mirror mirror`
- `Arrival mirror` 属于主展廊这个房间，对称面是主展廊的**横向中切面**（x ≈ 8.9，即两端墙的中点）。
- 副本出现在 x ≈ −18 的远端墙（`Missing end wall`）上，高度和横向位置与原件一致（z=0，正好在展柜／天平的正后方），朝向镜像。
- **副本是一条可用的通道**：走进副本同样回到开阔地（全功能副本）。拆句后副本消失。
- 副本正好在天平背后，**刚出现时被展柜挡住、走不进去**，要用 `mirror move` 把它挪开（已定保留）。

### 6.2 `mirror move`
- 镜子没有轴，所以是**布朗运动**：在所在墙面上平滑随机游走（建议用 Ornstein–Uhlenbeck 式的随机速度，平均 0.6 米／秒，不抖动）。
- 原件和副本都动，副本永远是原件的镜像，所以两面镜子在各自的墙上同步游走。
- 活动范围：
  - 横向：墙宽内两侧各留 2 米。
  - 竖向：**不限制**（已定），整面墙内都可以去，允许停在够不着的地方。
  - 展柜后方也不避开。
- 停下：停在当前位置。
- 主展廊和维特鲁威人房间是两个空间，入口镜子的活动范围只在两端墙上，**不会挡住方形的光路**（用户担心的情况在这个布局下不会发生）。

### 6.3 方盒未展开时【已定】
- 到达方盒合拢时（`on world` 展开前），玩家在 6 米方盒里，`Arrival mirror` 在盒的固定后墙上。
- 此时方盒是自己的结构：`mirror mirror` **成立**，副本出现在**方盒对面的盒壁**上（对称面为方盒的横向中切面）。
- `on world` 展开方盒时，副本随那面盒壁一起翻倒、没入地下；`mirror mirror` 这句**自动消失**（整句淡出、词回词库，表现同一次性句完成后的归库）。原件在固定后墙上，不受影响。
- `mirror move` 在盒内：原件在后墙范围内游走，副本（若存在）在对面盒壁上做镜像运动。

### 6.4 验收（随批次 6）
- [x] 主展廊 `mirror mirror`：远端墙天平背后出现镜像副本；走进副本回到开阔地；拆句后副本消失。
