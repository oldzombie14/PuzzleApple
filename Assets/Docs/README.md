## 阅读与维护

- V1–V3 历史文档归入 `Archive/`；其中也保留整理前混写的 V4 修订。仅在用户明确要求追溯时阅读，不自动搜索、预读或作为当前依据。
- `ProjectHelper/` 是原位保留的 V3 设计工具，同样仅在用户明确要求时查阅，其数据不构成 V4 需求。
- 确认变更后直接更新原段落，删除失效描述，不追加“本条覆盖上文／下文”。同一要求只在设计文档维护一次。
- 设计说明行为；编辑说明提供定位；进度只记开发状态，不写操作流水、参数试调、测试数量和截图过程。
- 用户当次明确指令优先；实现不是设计授权。复用旧版仅限明确指定部分，不自动继承旧规则。无法由已有确认消解的歧义，集中讨论后再做依赖该答案的修改。
