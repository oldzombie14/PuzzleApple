# C2C｜句号生效机制

正式交互与维护范围见 [V5 句号生效设计](../V5.md#句号生效设计)。

## 交互

- 拼词只产生草稿。所有多词组（含不通的组合）自动在句尾显示句号；单词没有句号。
- 草稿词透明度为 0.16。句号在 0.16–1 间缓慢呼吸，默认周期 2.5 秒；悬停用 0.15 秒渐亮，使用现有交互白点指针。呼吸不缩放、不附加涟漪。
- 可判定的有效草稿各自循环显示句号涟漪。一次性动作执行期间暂停所有判定提示。
- 在句号上按下并在同一句号上松开才说出。移动超过原生拖拽阈值不算点击；草稿不能拖。
- 选框使用整句涟漪扩散过程中短暂停留时的矩形，保持静止。两者共用内容范围和横纵留边，句号按圆点右缘计入。选中可编辑句后，在框内任意位置右键消融整句。未选中时，右键词只消融该词；右键句号只消融句号，持续句回到草稿。单词与草稿也可以右键移词。对持续句，拆词或把句号拖出整句范围后松手会暂停。执行中的一次性句连同句号锁定。拖动后在句内松手保持说出；拖到别句不转移句号。
- 拖出后圆点原地淡出，再在句尾出现草稿句号。没有角落供应、吸附、拖拽尾迹或指针涟漪。
- 词继续沿用原有面板外投放／回收规则；拖句号不产生世界交互。

## 状态与反馈

`Spoken` 与语法识别分离；有效句为 `Recognized && Spoken && !Conflicted`。草稿不占冲突通道，不播放效果、镜头或历史。点击调用 `Speak`，暂停调用 `Unsay`。成立先后顺序在说出时确定；持续句遇到冲突时保留说出状态，解除后自动恢复。一次性句未执行时保留草稿，反馈结束即恢复句号提示，每次重试由玩家点击。星芒与三档明暗见 V5 主档。

不通的词组点击后保留完整句子，整句划线，记录一次失败；编辑或暂停清除划线。改变词序或词数会撤销说出状态，留下的多词组需要重新点击。这样拼 `light move floor` 不会先执行 `light move`。

执行期间仍可编辑其他句子和收词，新授予的例句保留为草稿。空闲时授予的例句沿用原有判定。一次性句从生效到完成不能拆改、回收或取走句号。完成后词归库，句号一起消失；句尾圆点计入整句反馈范围。跨章节清空组句区时删除所有句尾句号。

## 暂停与继续：全局方案 A

物体保持停止时的位置、方向、相位和进度。重新说出、拆词重组或解除 `no move` 后，沿原方向和相位继续；只在首次开始时随机方向，反弹等物理事件照常改变方向。已点亮／熄灭的灯保持当前值；持续效果可随拆句暂停，一次性开关灯渐变执行至完成。跨章节遵循各对象已有的回访复位规则。

作用范围的目标设计独立见 [生效范围：进度锁与薄膜门](生效范围-进度锁与薄膜门.md)，由批次13实施。句号不自行保存或恢复空间范围。

## 实现与检查

- `CognitionState` 管理草稿、说出、冲突和历史；`PeriodTray` 管理句尾圆点、呼吸、逐句涟漪和拖出淡隐；`PeriodGlyph` 使用 Unity 原生指针与拖拽事件。
- `CognitionDragHandle` 使用原有消融移词／移整句路径；句号右键由 `PeriodTray` 暂停并调用共用消融效果，结束后恢复草稿句号。
- `Punctuation` 仅保留点径、命中区、呼吸、悬停、淡隐和逐句涟漪参数。
- `PeriodChecks` 按点击交互验证；`MirrorChecks`、`VitruvianChecks` 使用实际点击／拖出；`MotionPauseChecks` 检查运动暂停后的方向和相位。当前验收采用正式句号设计。
