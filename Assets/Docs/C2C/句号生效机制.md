# C2C｜句号生效机制（试验功能）

当前交互以 [第三轮 §1](第三轮-验收修改.md#1-句号从拖拽改为自动出现--点击批次-12) 为准；实现与验收进度见 [执行计划](00-执行计划.md#第三轮实现进度)。本机制保留总开关，是否长期保留待用户试玩决定。

## 交互

- `V5Interface / CognitionBoard / Require Period` 开启时，拼词只产生草稿。所有多词组（含不通的组合）自动在句尾显示句号；单词没有句号。
- 草稿词透明度为 0.16。句号在 0.16–1 间缓慢呼吸，默认周期 2.5 秒；悬停用 0.15 秒渐亮，使用现有交互白点指针。呼吸不缩放、不附加涟漪。
- 第一个语法成立的草稿有循环句号涟漪。第一次点击任一句号后，本次运行永久关闭引导，切换试验开关也不重置。
- 在句号上按下并在同一句号上松开才说出。移动超过原生拖拽阈值不算点击；草稿不能拖。
- 右键统一消融，词／整句手柄／句号的移除范围按 [第三轮 §1.2](第三轮-验收修改.md#12-细节建议) 的已定规则执行，单词与草稿同样适用。拆词、把句号拖出整句范围后松手也会暂停。拖动后在句内松手保持说出；拖到别句不转移句号。
- 拖出后圆点原地淡出，再在句尾出现草稿句号。没有角落供应、吸附、拖拽尾迹或指针涟漪。
- 词继续沿用原有面板外投放／回收规则；拖句号不产生世界交互。

## 状态与反馈

`Spoken` 与语法识别分离；有效句为 `Recognized && Spoken && !Conflicted`。草稿不占冲突通道，不播放效果、镜头或历史。点击调用 `Speak`，暂停调用 `Unsay`。成立先后顺序在说出时确定；并存、冲突接管、弱反馈、循环泛星沿用句子系统。

不通的词组点击后保留完整句子，整句划线，记录一次失败；编辑或暂停清除划线。改变词序或词数会撤销说出状态，留下的多词组需要重新点击。这样拼 `light move floor` 不会先执行 `light move`。

观察授予的例句直接为已说出。一次性句完成后词归库，句号一起消失；句尾圆点计入整句反馈范围。跨章节清空组句区时删除所有句尾句号，保留本次运行已经完成的首次引导状态。

`Require Period` 关闭时恢复拼完即生效，移除全部句号 UI，保留原来的右键移词行为。

## 暂停与继续：全局方案 A

物体保持停止时的位置、方向、相位和进度。重新说出、拆词重组或解除 `no move` 后，沿原方向和相位继续；只在首次开始时随机方向，反弹等物理事件照常改变方向。已点亮／熄灭的灯保持当前值；尚未完成的渐变暂停在当前值。跨章节遵循各对象已有的回访复位规则。

作用范围的目标设计独立见 [生效范围：进度锁与薄膜门](生效范围-进度锁与薄膜门.md)，由批次13实施。句号不自行保存或恢复空间范围。

## 实现与检查

- `CognitionState` 管理草稿、说出、冲突和历史；`PeriodTray` 管理句尾圆点、呼吸、首次涟漪和拖出淡隐；`PeriodGlyph` 使用 Unity 原生指针与拖拽事件。
- `CognitionDragHandle` 在两种模式下均使用原有消融移词／移整句路径；句号右键由 `PeriodTray` 暂停并调用共用消融效果，结束后恢复草稿句号。
- `Punctuation` 仅保留点径、命中区、呼吸、悬停、淡隐和首次涟漪参数。
- `PeriodChecks` 按点击交互验证；`MirrorChecks`、`VitruvianChecks` 使用实际点击／拖出；`MotionPauseChecks` 检查运动暂停后的方向和相位。两种开关状态都需要回归，实际结果见执行计划。
