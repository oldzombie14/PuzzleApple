# V5 当前设计与开发

入口：`Assets/Scenes/V5/P5.unity`，可直接 Play；编辑器菜单 `PuzzleApple/V5/Open`。

## 已确认要求

开始界面沿用 V4 的符号与淡出流程。点击 on world 后进入非常昏暗的小正方体空间，进入后自动打开左侧 Tab，初始符号只有 on／off／world。V5 普通表面（大小盒、通道地面与门、灯群房间墙地顶）统一使用 World Surface Shader，采用纯白哑光与细黑边。通道口流线、灯体发光及 UI 继续使用原专用 Shader；门的铰链开合、碰撞涟漪、壁画及开洞保留原效果。内外空间墙面统一纯白、统一高粗糙度哑光材质，不混用光滑高光质感；暗度通过照明控制，不把墙材质染灰。空间保持黑白灰；白色表面关闭环境反射与镜面高光，避免关灯后残留蓝色环境反射；灯群自发光使用中性白。小盒墙角与墙顶贴合，不再保留实际缝隙，保留原来的 Shader 边缘亮线；顶部、底面与周围墙面保持相同色相和暗底；外盒沿墙角、顶边和地面边沿显示细黑边；降低均匀补光并拉开地灯与墙面的明暗，保留纯白哑光材质。

拼句的拖拽、涟漪／星芒及音效沿用 V4 的表现，玩法按 V5 独立实现。on world 使小空间按 V4 的铰链折纸方式展开，露出更大的方形空间。展开结束时不自动打开面板。off world 生效并触发退出确认时先播放带星涟漪，盒子已合上或当前区域直接弹确认时也一样。关盒时冻结玩家位置但保留转向和视角，从玩家脚下反向折合小空间，关回后稍作停顿，再淡入 on／off 确认 UI；on 关闭游戏，off 或 Esc 取消确认并返回游戏；Esc 与 off 使用相同的就绪条件。初始界面、Tab 右上角及退出确认的 on／off／world 按钮统一为未悬停较淡、悬停更白更亮。目前不做存档，不放 BGM。

开局玩家与闭合小盒位于大空间侧边，展开后玩家朝向地面正中的立方体灯。灯底贴地，瞄准可收集 light，on/off light 渐亮／渐灭，暗灯不能收集。学会 move 后返回原房间，light move 也驱动该灯在原房间内移动与碰撞反弹；拆句暂停、重组恢复，明暗与运动独立。灯体的子点光源随灯移动。每次启动随机选择一面墙，在该墙水平正中设置抬高洞口，开合不重新随机；洞口始终可通行，开灯时显示完整墙外观，关灯后从大空间透过洞口可直接看见墙外的白色小道，四边保留原有流动细线；细线沿洞口四边的固定直线平移，使用错相线段，不做弯曲或波浪摆动。穿过洞口进入纯黑环境中的白色小道，回头可见入口的发光轮廓，原房间建筑隐藏，仍可返回，边界阻止玩家落下；点击白门获得 door；通道侧白门带同材质的白色圆球把手，门洞保留动态细线边框。on door 使门绕左侧竖轴向灯群房打开 90°，off door 原路关回。拆句暂停在当前角度，恢复后继续。两间房在关灯时保留微弱中性补光。新房间初始昏暗，重新拼 on light 后渐亮；灯无论明暗均持续随机方向运动、碰墙反弹，不与玩家碰撞。通道是否允许关盒尚未定案，应保持可配置。

## 词库快照

on／off 共用菜单图，world 使用应用图标，沿用 V4 原图的 V5 副本。light 保存首次收集时准星附近的实际世界画面，重复收集保留原图。door 为 P5 白门正面的正交静帧；floor 为水平取景的地面与碰撞涟漪，画面内无灯体。move 使用飘灯房固定机位录制的单个方块移动与碰壁片段，往返循环。图片、帧图集和播放配置绑定在 V5Interface 的 WordLibrary。

## 句子历史

已确认：移除一键清理入口，原位置改为历史按钮，与笔记保存共用旧 floor 符号（Sprites/V5/Save.png）；floor 词汇使用新 Floor.png。两张 PNG 已处理透明底并居中，原图保留于 ArtSource/V5/Symbols。历史向右展开，与主侧栏留小间距，使用同款滚动条，当前高度显示五条；词库与历史共用滚动手感：滚轮输入先按 Input System 的每格增量归一化，约 0.09 秒缓动，单格最多移动可滚动范围的 10%；滑块拖动保持原生直接跟手并取消滚轮缓动。成立句正常颜色，不成立句划线。历史只读，与左侧组句共存；Tab 关闭时先收历史，再收主栏。暂不制作收藏或拖回句子的功能。

实现假设：历史仅保留本次运行的多词组合及当时判定；相同句子与相同结果合并并置顶，成立／不成立两种历史结果可分别保留。冲突解除后的成立结果也记录，拆句不删除历史；单个散词不记录。历史收起约 0.12 秒，主栏沿用原动画。配置与布局位于 V5Interface，行为为 SentenceHistory，记录属于 CognitionState。

验证：SentenceHistoryChecks 在 P5 Play 通过成立／不成立记录、冲突接管、拆句保留、历史展开时实际拖词回调、划线、原生滚动和顺序收起／重开。实际窗口已核对五条高度、间距及符号；Unity 编译和运行无错误，未验证独立构建。

## 本轮实现假设，待试玩确认

灯、门的相反状态句采用 V4 的先成立优先规则，冲突句不生效。拆句停止对应渐变或移动，保留当前连续值；重新成立后继续。world 句保留进入／关盒退出的独立流程，完成状态不因拆句倒退；取消退出不自动重复弹窗。盒子动画中可用 Tab 返回编辑，拆句暂停姿态；半闭合时保持位置锁定而允许视角与编辑，展开完成后恢复移动。

本轮先选约 26 米小道和 16×8×18 米新房间。新房间放置 8 盏运动灯，采用原生 Rigidbody 与球形碰撞，保留灯间碰撞；灯体采用 V4 GlowingCube 与 WorldGlow 的独立 V5 副本，通过 HDR 自发光与 Bloom 柔化几何轮廓，不再使用包围灯体的光圈；房间保留基础环境补光，运动灯使用原生点光与柔阴影，让墙、地面及道具随灯的位置和距离受光；哑光表面对近距离高亮做平滑压缩，防止墙面被 Bloom 当成光源。灯体通过 HDR 发光、Bloom 和薄雾形成柔光；当前为雾感近似，没有启用完整体积散射。完全熄灭时灯体不可见，物理运动仍继续。灯句作用于玩家当前房间，各房间保留自己的明暗状态；进入新房间不会因面板留着旧 on light 自动亮灯。通道暂允许关盒，最终规则待用户决定；关闭 Allow Corridor Closure 时改为直接显示退出选项，保留退出能力。门底边与白色走道同高、同宽；入口洞口、门扇与新房间门洞共用宽高，当前为 3.6×3.8 米。

小房间暂为 6 米立方体。外盒本轮按用户在 Unity 中摆放的顶面试调：保持顶面中心 Y=16.12 米，净空间 28×15.92×28 米，四周墙高与顶面衔接；暂不要求维持此前等高的立方体比例。靠外墙合拢时，小房间中心向内部收进到能容纳的位置，玩家不位移。小盒墙角与顶边无预留净缝，墙底伸入地面避免漏光；使用原生墙板和灯光，没有额外体积光。已检查四角与墙顶贴合，FoldingInteriorChecks 通过闭合暗底、展开过渡，以及通道和灯群房间的合拢／取消／重开回归。

## 编辑位置与资源边界

场景中的 Small folding room / FoldingRoom 配置各墙和顶板铰链、开合时长、下沉距离及可落位范围；闭合与展开共用同一可逆时间轴。墙、地面、顶板和灯都是 Unity 原生对象，日常直接编辑场景，不重跑 V5Setup 覆盖手调。

小盒闭合时，Contain Player While Closed 额外约束完整玩家胶囊体，边界从闭合墙板与顶板的实际内侧计算；独立于几何贴合和光照。开始展开后解除约束，之后再次闭合会在小盒当前位置恢复。此约束独立于墙板碰撞，用于阻止接缝漏判造成跳过 on world。当前保存场景中未稳定复现用户报告的穿缝路径；新增约束已检查四周、角落、跳跃、较大移动步长及临时关闭墙板碰撞的情况；已确认原生落地／起跳正常、展开后自由移动，以及 off world 重新定位后的闭合约束、取消／重开和通道流程。

World Entry 配置入场淡出、退出遮罩和按钮，Closed Pause Duration 与 Dialog Fade Duration 分别控制合拢后的停顿和选项淡入（当前 0.65／0.5 秒）；Sentence feedback 配置涟漪、星芒、E5 音效与音量。Player / FirstPersonController 负责位置锁定与视角；V5 的锁定包含重力。从词库或组句区拖出单个词，在面板外松手时立即移除拖拽图形，不在面板内播放消融；室外可投放的词仍执行世界交互。V5Interface 保留 V4 面板的布局和拖词表现，初始获得 on／off／world；地灯收集后解锁 light 及 on/off light。

Outer spot lighting / RoomLighting 继续驱动外部开合照明与道具环境补光，中心点光 Dim room bounce 禁用。小盒使用独立的 Folding Panel shader（Shaders/V5/FoldingPanel.shader），只保留原生受光、闭合暗底和单层像素描边；Small folding room / FoldingInterior 驱动材质 FoldingInterior；Core Brightness 保持原值 0.18；Edge Width Pixels 控制接缝总屏幕宽度（默认 1.5 像素，两侧表面各承担一半），不用世界米数决定线宽，避免靠近墙面或斜视时变粗；取消实际几何缝隙不等于取消边缘亮线。体积雾自然产生的发光可以保留，但本轮不额外添加体积雾。外表面通过 Folding Panel 保留原生 URP Lit 受光和单层细黑边，展开按 FoldingRoom.Progress 平滑交接正常照明。参数集中在组件：Dark Level、Core Brightness、Edge Width Pixels、Tint、Handoff Start/End；亮线宽度单位为屏幕像素，图案使用板局部坐标，随折叠和跨空间搬移；闭合和展开始终按面 UV 的真实四条边画同一层线，颜色随闭合暗底过渡，不使用补偿矩形。禁用该组件可回到普通受光，原 SmallRoomWhite 材质保留以便比较。小盒六块板使用 Meshes/V5/FoldingPanel0–5 的斜切厚板网格：内外各八个角由相邻三板共用坐标，避免覆盖式顶板产生凸角或缺角；铰链位于实际内侧接合边，动画时间轴保持原值。原生 BoxCollider 保留为简化碰撞，FoldingInterior 只传递暗底、线色和宽度，不再计算几何边界。大空间 OuterRoomEdges 按六面内壁共用交界绘制等像素黑线，避免墙厚遮掉竖向半条线。相机曝光和盒内新增道具仍属于场景边界。大空间地灯保留原立方体模型，独立 ChamberLamp Shader 缩小三个面的亮度差，以中性 HDR 发光和独立 Bloom 柔化几何轮廓；ChamberLight 从材质读取亮灯颜色与发光，再驱动渐变。World Surface（Shaders/V5/WorldSurface.shader）用于大空间、通道及灯群房间，小盒独立使用 Folding Panel；保留各空间材质与亮度驱动。Edge Width / Ink Color 控制像素细黑边，黑边乘入表面颜色，关灯不会发亮。小盒闭合时使用统一暗底与原有边缘亮线，展开恢复正常受光与细黑边。房间普通表面通过原生 URP PBR 受光，灯群房间使用连续平滑明暗，不启用色阶；Surface effects 区分普通表面、通道和房间特效；通道纯白试验跳过受光与雾的灰度压暗，门背面仍使用房间受光；WorldSurfaceEffects.hlsl 保留 Impact Floor 的涟漪、壁画、开洞算法与参数。灯群房间按完整内壁边界描边，不描出门墙分块接缝；门背面仍匹配墙色，不暴露隐藏入口。地洞投影 Pass 与可见面使用相同裁切；带裁切材质不使用原生实心深度预通道，前向 Pass 正常写入裁切后的深度。RoomLighting 的 Unfolded Spot Contribution 与 Unfolded Ambient Lift 平衡聚光与环境补光，外盒保留顶部照明层次，提高均匀补光使墙体更白（P5 的 Unfolded Ambient Lift 为 0.4），地灯适度增强中性自发光，闭合盒内照明不变。V5 独立 ChamberBloom 柔化地灯，灯群 WorldGlow 柔化移动灯；墙面高亮压缩将柔光主要留给灯体。进入通道／灯群房间后取消 ChamberBloom 覆盖，不修改共享质量 profile。

所有复制资源使用独立 V5 GUID、命名空间与 Shader 名；位于原有资源类别下的 V5 目录，不改 V1–V4。保留共用工程设置，不自动改 Build Settings。不加载 V4 会话、音乐或天空提示存档组件。

## 编辑器启动

P5 单场景 Play 由 P5FastPlay 临时启用 Unity 原生 Disable Domain Reload，保留场景重载；停止后恢复原工程设置，其它场景沿用原设置。V5 游戏状态归场景实例所有，当前无需要跨运行清零的可变静态游戏状态；以后新增静态缓存或事件时需处理重置。修改脚本后的正常编译／域重载仍会发生。已定位原 Play 的主要等待为编辑器域重载及插件初始化（日志约 15–17 秒）；连续两次快速启动测得进入 Play 约 2.2 秒和 0.23 秒，按钮就绪、词组／历史清空、盒子闭合及再次入场通过。此结果针对编辑器，未测试独立构建启动。

## 进度与验收边界

地灯可从初始小盒展开处直接瞄准收集。

玩家已增加 Space 跳跃，Jump Height 可调；沿用原生 CharacterController，落地才可起跳，面板操作和位置冻结期间禁跳。Unity 运行检查覆盖起跳、空中不能重复起跳、落地及冻结状态，实际按键手感待试玩。

## 行为观察与持续句子

亮灯时地面为白色；灯实际碰撞地面时，在接触点出现约两圈黑色扩散涟漪和少量大小不一的方形粒子。地面可按既有方式收集 floor；正对入口的墙面居中显示两幅浅刻壁画：左侧为散乱悬空的方块与地面，中间箭头指向右侧落在地上的同组方块。方块大小、朝向各异，下降前后保持水平对应及倾斜姿态。壁画下方居中横排词库中的 light、floor、move 三个符号，符号保留 floor 的下对齐，边缘与凹槽使用与壁画一致的浅刻明暗，随墙面受光。

壁画由 Blender 原生立方体草模正交投影生成凹刻高度及法线，直接在 World Surface 的房间特效配置中取样，没有新增墙前平面或碰撞体。当前为法线模拟浅刻，轮廓不产生真实几何位移；凹刻细节保留局部固定方向的明暗，再随墙面真实受光变化。FloorImpactSurface 的 Mural Size / Height / Relief / Cavity / Light Direction 控制尺寸、高度、凹槽强度和局部明暗；纹理为空时加载 V5/Murals/GravityMuralNormal。法线使用线性普通 RGBA 纹理，RGB 为切线空间法线、A 为凹槽遮蔽，不能改为 Unity Normal Map 压缩导入。贴图位于 Textures/V5/Resources/V5/Murals，包含两张独立壁画及带箭头的合并图。Blender 源文件和可重烘焙脚本位于工程根目录 ArtSource/V5/GravityMural；运行 build_mural.py 只生成独立源场景，不覆盖原 Blender 场景。涟漪、粒子和洞口参数仍在 FloorImpactSurface。

壁画已检查 P5 实际渲染、法线加载、熄灯归黑与墙面撞击回调共存；替换后 FloorImpactChecks 的先开灯流程通过，覆盖收词、撞地、下降、拆句暂停／恢复、开洞与坠落。C#／Shader 无编译错误，未做独立构建；浅刻的视觉强度待试玩验收。未保存覆盖 P5 的既有未保存编辑。

light floor move 沿用 V4 向地面移动的方式：保持水平位置，以碰撞检测约束竖直下降，保留原有贴地间距。它与 light move 共用移动排他通道，先成立者生效，后者沿用 V4 的淡化冲突表现；拆句暂停，重组恢复。off light 不影响下降。所有灯抵达地面并且灯开启后，地板中央的正方形洞从中心向四周约 1.4 秒展开；视觉洞口与四周实际碰撞范围同步扩大，四周保留地面，玩家可落到世界外。洞下通过 OutdoorPassage 衔接开阔场景。

## 语法与演出接入

SentenceRuntime 区分请求句子与已应用效果：相反灯／门状态互斥，重复同效果可共存；新效果可等待演出开始，拆句立即更新，冲突接管不播放镜头。on/off light 继续作用于组句所在空间，不因跨房间自动重放。观察授予 light move 直接接管预设运动并打开面板，不因授予过程再收回面板。off light 不阻止任何已生效的灯移动。

SentencePresentation 负责反馈完成后的全屏电影黑边、转向、效果应用、跟随和恢复。当前为基础版，具体演出以后逐句设计；cutscene 全程锁定玩家移动（包括重力），摄像机位置固定，只调整 pitch 和 yaw，保留起始 roll；演出正常播完后保留当前朝向，自动锁回鼠标并恢复准星和游戏控制，无需点击，Tab 面板保持关闭，不自动弹出；新效果开始后允许玩家主动按 Tab 中断镜头，保留朝向返回编辑。独立配置为 GameData/V5/Resources/V5/SentencePresentation.asset，按完整句式调整目标、偏移、时长、黑边与跟随。没有绑定镜头的句式直接应用；世界退出保留专门确认流程。FloorDirectedMotion 对尚未完成初始化的引用安全返回，避免先执行物理帧时空引用。
