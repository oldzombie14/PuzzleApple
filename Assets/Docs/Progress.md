## 使用与调整
- 场景 `GameplayPanel` 或对应 Prefab 的 `GameplayPanel` 组件：`Background Color` 改背景色；`Width Fraction` 改覆盖比例；`Slide Duration` 改展开时间；`Stop Duration` 改停步时间；`Look Angle` 改 yaw 幅度，`Idle Pitch Angle` 改上下 pitch 幅度。默认黑色、1/3、0.25 秒、0.2 秒、yaw ±2.5°、pitch ±0.35°。
- 玩法 UI 放在 Prefab 的 `Panel/Content`；通过 `ContentRoot`、`IsOpen`、`OpenChanged` 和 `SetOpen` 接入。场景保留独立 EventSystem，玩家引用在场景绑定（其他场景可显式绑定或由 Awake 查找）。后续场景物品交互必须检查 `FirstPersonController.CanInteractWithWorld`，面板打开时该值为 false；透明 `WorldInputBlocker` 仅拦截 UI 射线，不能替代未来物品交互逻辑的状态检查。
- 面板展开后鼠标可自由经过整个画面，idle 已按最新反馈改为连续低频 yaw＋极轻 pitch，随机初相位、2 秒淡入、无 roll 或相机位移，去掉旧版“停顿—转头”节奏。120 秒模拟检查 yaw/pitch 范围、水平保持、位置不变、双幅度设 0 和收起时 pitch 衔接通过，控制台无错误或警告。收起后恢复正常鼠标视角和 WASD；本次真人手感待反馈。
- 运行时统一设置 60 FPS 目标上限（`FrameRateSettings` 启动时自动应用，无需挂组件），关闭运行时 VSync，避免高刷新率屏幕覆盖 60 帧设置。适用于编辑器 Game 视图和桌面构建；不限制 Scene 视图等编辑器界面刷新。
