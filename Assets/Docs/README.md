# PuzzleApple 项目文档

**V5 是唯一正式开发版本。** Unity 编辑和构建都从 `Assets/Scenes/V5/P5.unity` 进入。P5 运行时加载开阔地预制体，穿过画框进入 Chapter I 教学方盒，乘星空平台穿过白光后，叠加加载展廊、花房和维特鲁威人房间。继续游戏计划时，先看[当前进度与验收边界](V5.md#进度与验收边界)。

| --- | --- |
| 开发、修复或验收玩法 | [V5 主档](V5.md) |
| 继续句子系统重构 | [现有结构](V5.md#句子系统结构) · [六步计划](C2C/句子系统架构.md#对当前实现的修改建议分步) · [已确认的行为与边界](C2C/句子系统架构-QA.md) |
| 核对正式句号或命令范围 | [句号生效设计](V5.md#句号生效设计) · [进度锁与薄膜门](C2C/生效范围-进度锁与薄膜门.md) |
